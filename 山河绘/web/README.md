# 山河绘 · 绘画工作台

双击项目根目录的 **启动绘画工作台.bat**，浏览器会打开 [绘画工作台](http://127.0.0.1:8765)。原“启动山河汇.bat”也可继续使用。

## 操作流程

1. 从首页五幅参考图中选择作品：松瀑亭舟、松岸曲水、云山亭阶、柳岸渔舟、青绿梯田云山。窄屏会换行，五幅仍全部可选。
2. 默认选择“机械臂绘画”。在“本次先画”选择黑线勾勒、某种颜色上色或题字，点击“开始绘画”，确认纸张、毛笔和对应墨色准备好后开始。后台检查画稿和现场设置，再调用项目已有绘画执行器。
3. 画布从空白开始。机械臂每确认完成一笔，网页就在画布添加对应笔触；整体、勾勒、上色及各颜色的进度同步更新。
4. 勾勒、每种颜色和题字均可独立执行，不再限制先后顺序。例如只上色、只题字、勾勒后直接题字。每阶段完成后停靠，准备好下一阶段的墨色后点击对应按钮，或点击“结束作画”。同一任务中已完成的阶段不可重复选择；未选阶段保持未完成。每阶段内部的笔序不变。换色前请等墨干、洗净并擦拭毛笔。
5. 全部完成后提示取下作品、清洗毛笔。可以保存当前画布，或打开 [独立大屏](http://127.0.0.1:8765/screen) 展示过程。

“暂停作画”会完成当前笔并抬笔停靠，点击“继续作画”从当前阶段下一笔继续；阶段切换在当前阶段完成后进行。“结束作画”仅在停靠等待操作时可用。需要立即停止时，使用机械臂控制器急停。网页默认不保存续画进度：暂停和继续只在本次运行内有效，结束后重新开始会从新选阶段第一笔绘制。若在同一张纸上补画其他阶段，必须保持纸张位置和标定一致；重画同一阶段会重复落墨。全画稿进度只统计本次实际绘制的笔触。

自由选阶段功能需要更新后的后台。若已有任务运行，请先正常结束，再双击“启动绘画工作台.bat”重启并刷新页面。新页面会识别旧后台并阻止启动新任务，避免所选阶段被旧后台忽略；已有任务的暂停、继续、换色和结束仍可操作。原终端入口默认保留原有顺序。

“离线预演”可以体验完整流程，不连接机械臂、不写入实机进度。已有外部终端任务可以继续运行，预演不会操作它；新实机任务仍受原会话锁约束。

## 修改现场参数

作品卡片现在默认展示对应的 `参考原图.png`，不再使用程序生成的路径预览作为封面。后续将机械臂实绘照片命名为 `机械臂实绘.png`（也支持 `.jpg`、`.jpeg`、`.webp`），放在该作品的参考原图同一目录，卡片即优先展示实绘照片；刷新页面可立即更新，无需重启。原图按钮和画稿预览中的“参考原图”仍展示参考原图。多个格式同时存在时按上述顺序选择。

黑墨、蓝色、绿色液面补偿分别默认收起，点击标题展开，与“杯位与蘸色参数”的操作一致。收起只改变显示，不影响补偿开关或参数保存。

点击首页右上角“修改参数”，填写笔尖刚触纸的纸面高度，以及黑墨、蓝色、绿色三个杯子的液面高度，单位毫米，保留示教器读数的正负号。展开“杯位与蘸色参数”可以修改各杯中心 X/Y、杯沿高度、蘸入深度、停留时间和沥液时间。输入的是现场实测值，网页不会自动测量。

网页参数界面不提供速度和加速度调节。2026-10-10按用户要求，网页新作业的黑线、题字和上色纸面行笔速度指令在此前提速后再翻倍：前五幅画稿48→96，简化单线稿24→48，相对原画稿为2.4倍。黑线在生成轨迹时提速；上色在原速度上限内取值后提速，默认上限由45按2.4倍换算后封顶100，实际逐点速度40对应提高到96。原画稿文件、笔压、空移、落笔、抬笔、蘸取、全局倍率及加速度不变。2026-10-09按用户要求，上色不再下发 AccJ/AccL，而是沿用控制器当前加速度。配置中的加速度0表示“不发送设置”，不代表实际加速度为0或恢复100%；控制器先前的20%仍可能保留。变更只对新启动的网页绘画进程生效，不热更新正在运行的任务。速度数字是控制器指令比例，实际行笔速度受路径和加速度影响。1×、4×、12×仅为离线预演播放速度。

液面下降补偿可按杯设置开关、累计长度、单次下降和累计上限，当前为每500毫米下降0.1毫米，上限0.5毫米。

点击“保存并检查画稿”会离线检查杯位、允许运动范围和五幅画稿的路径；此操作不会连接或移动机械臂。全部通过后，参数独立保存到 web/data/site_settings.json，检查记录与上一版参数保存在 web/data/settings_checks。输入无效、检查失败或其他页面已更新参数时，保留原参数。机械臂绘画或洗笔任务尚未退出时，只能查看参数。

下一次从网页启动机械臂绘画时，后台固定一份本次参数快照，检查与执行使用同一份。依据新纸面高度，在内存中重新计算绘画高度和绝对轨迹；原始 painting.json 的构图、笔触、下压量与颜色计划不被改写，config.py 和 pigment_measurements.json 也不被改写。原终端入口仍沿用原配置，网页保存的参数只供网页新启动的任务使用。

纸面高度改变后，不会直接接着原纸上的旧进度画；原执行器仍检查纸张标定和续画记录。迁移场地后，如果纸张四角、工具坐标系或毛笔姿态也改变，需要完成相应标定；此按钮仅调整纸面高度与三个墨/颜料杯的现场测量。

## 实现与检查

- 首页只收录“待画作品”中的五幅含“山河绘”题字作品。参考图来自各作品目录，执行统一读取其中的“任务资料/painting.json”；旧“输出”“已确认”“展示选画”目录不再是五幅的运行来源。程序和现场标定保留在项目根目录。后续修改顺序以此材料库为准。
- 五幅的速度设置在检查和执行子进程内载入；网页现场参数不覆盖运动速度、倍率或加速度。物理标定检查、运动前检查、会话锁及按笔确认仍由原执行器处理。
- 网页启动的任务关闭磁盘续画进度，每笔完成后通过带认证的本机进程通信发送完成笔数、阶段和等待提示，网页后台仅在内存中维护实时状态；刷新网页仍可显示本次进度。进度来自运动确认，不按计时推测。屏幕画布展示绘画路径，墨晕、线宽和颜色与实物会有差异。
- 页面使用操作提示，不展示源码、任务文件路径、命令或异常堆栈。现场设置窗口展示高度、杯位、蘸取参数和液面下降补偿。详细诊断保存在本机日志。前端静态文件仅提供页面所需资源，不开放项目源码目录。
- 服务只监听本机。关闭网页不会停止机械臂；需要结束时先暂停，停靠后点击“结束作画”。后台服务须在整个任务中保持运行，关闭或重启服务会断开本次同步，不能自动续画。

无需 npm 安装，网页服务使用 Python 标准库；画稿检查与执行使用已有 NumPy / OpenCV 环境。也可在项目根目录运行 python web/server.py --open-browser。

## 不保存进度与清空记录

新网页任务从第一笔开始，不继承旧任务的已画笔数。当前任务的计数、洗笔提示和暂停/继续命令通过本机内存通道传递，不写 status.json 或 runtime.json，不在每笔边界写入会话进度或黑线执行日志。后台仅保留任务开始、阶段切换、结束或异常的安全标记，以及最终诊断；这些标记没有可续画的笔数或画稿清单。原终端入口的保存选项不变。

“清空之前作画记录”会重置网页画布和当前内存状态，并把 robot_runs 下的完整绘画会话与上色记录、旧网页控制记录移到 robot_runs/cleared_records 的独立归档目录。画稿、现场参数、参考图和执行诊断保留。该按钮不发送停止或移动指令；任何绘画或上色任务未退出时均拒绝清空。操作者需确认机械臂停止、旧队列取消、毛笔离纸后执行，清空后换新纸重新开始。旧失败任务仍受原执行器的异常守卫约束，不会被不保存模式自动绕过。

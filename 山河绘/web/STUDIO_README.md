# 制作新画稿

工作台“待画作品”标题旁的“制作新画稿”进入 `/studio`。页面与既有五幅画的选择、绘画和现场参数流程独立。

1. 上传 PNG / JPG / WEBP 图片（小于 20 MB，边长 32–8000 像素），点击“提取勾勒线稿”。
2. 对照原图查看实际勾勒路径，可按短线长度、笔压倍率、整体顺序重新整理，也可在画布或列表选择笔触，单独移除或上移/下移。
3. 选择已通过杯位检查、已接入现场参数页的蓝色和绿色颜料，调整铺色间距、方向、下压量和预览浓淡，生成色区内的铺色路径。其他历史颜料杯可能仍是旧笔读数，本页面暂不提供。不选颜料可以制作纯勾勒画。可以调整建议选色顺序和同色笔触顺序；实际绘画仍逐色等待操作者确认。
4. 使用合成预览和逐笔预演检查画稿，再执行最终检查。点击“加入画库并进入工作台”保存新材料并选择这幅画。网页仍需要现场确认后才启动机械臂。

修改勾勒会清除当前草稿中的旧上色路径和最终检查状态，需要重新生成上色及检查。每次处理结果保存在独立版本目录，失败时保留最后完成的版本。已加入画库的画稿不被后续草稿编辑覆盖。

草稿与处理中间结果位于 `web/data/studio`，通过检查并确认加入画库的材料位于 `待画作品/新作品/作品名_编号`。新作品含完整 painting.json、参考原图和制作参数；新代码仍在 web 目录，已有五幅作品的画稿不被改写。

生成进程明确禁用网络连接，不发送机械臂指令，不保存或清理实机进度。算法调用现有通用提线与墨量规划，以及色区内的蛇形铺色。彩色区域近似映射到选定的实际颜料；线宽、颜色和晕染预览为估计。主要面向浅底、线条清晰的参考图，照片等复杂图片需要通过预览和调整判断效果。

独立离线测试：`python -m unittest tests.test_studio`。

# 山河绘：项目安装与使用说明

更新日期：2026 年 10 月 7 日。适用于当前 Windows 本地项目，示例目录为 `G:\山河绘`。换到其他电脑时，将命令中的项目目录换成实际解压位置。

本文覆盖获取项目、安装 Python 和依赖库、启动 Web、配置机械臂、制作画稿、日常作画和故障排查。已有环境能够正常运行时，直接从第 5 节开始。

## 1. 项目能做什么

山河绘将参考图转换为黑线和蓝绿上色路径，保存成绘画 JSON，再通过本地网页或终端控制 Dobot E6 绘制。

- **离线使用**：查看原图、逐笔预演、制作新画稿、检查轨迹，不需要连接机械臂。
- **实机使用**：完成现场标定和准备后，黑线勾勒 → 分色上色 → 最后题字。阶段之间由操作者洗笔、准备颜料并确认继续。
- **当前画库**：松瀑亭舟、松岸曲水、云山亭阶、柳岸渔舟、青绿梯田云山。

网页预览展示规划路径。下压量、纸上笔宽和颜色覆盖率是不同概念，实物效果需要用当前毛笔、颜料与纸张确认。

## 2. 获取项目与准备电脑

### 2.1 获取项目

将完整项目文件夹或交付压缩包解压到固定目录，例如 `G:\山河绘`。当前交付目录不是 Git 仓库，也没有可核实的远程仓库地址，因此本说明不提供假定的下载链接。

至少保留这些内容：

| 内容 | 用途 |
| --- | --- |
| 根目录全部 `.py` 文件 | 绘画、标定、轨迹检查及机械臂通信 |
| `requirements.txt`、`pyproject.toml`、`uv.lock` | 依赖安装与版本管理 |
| `web` | 网页、后台服务和新画稿制作 |
| `待画作品` | 当前作品原图、执行 JSON、预览和历史版本 |
| `scripts` | 生成、检查和部分画稿修订工具 |
| `config.py` | 机械臂、画布和现场配置 |
| `pigment_measurements.json` | 颜料杯测量与蘸色参数 |

不要只复制网页文件，否则画库和执行器可能缺失。迁移时保留工作资料；从其他电脑复制来的 `.venv` 应在新电脑重新创建，虚拟环境通常不能直接搬用。[Python 虚拟环境说明](https://docs.python.org/3.12/library/venv.html)

### 2.2 所需软件

| 软件或设备 | 是否需要 | 说明 |
| --- | --- | --- |
| Windows 64 位电脑 | 当前主要运行平台 | 本说明按 Windows PowerShell 编写 |
| Python | 必需 | 项目声明最低 3.10；当前项目环境采用 3.12，重建环境优先使用 3.12 64 位 |
| Edge、Chrome 等浏览器 | Web 使用必需 | 访问本机工作台 |
| uv | 可选 | 项目提供锁文件，可用它重建依赖 |
| VS Code | 可选 | 编辑代码、查看配置和选择解释器 |
| Anaconda | 可选 | 不需要专门为本项目安装 |
| Dobot E6 及对应控制软件 | 实机绘画需要 | 离线预演不需要 |

Web 使用 Python 标准库提供 HTTP 服务，基础安装不需要 Node.js、npm、CUDA 或额外的 Python 机器人 SDK；机械臂通信驱动位于本项目 `robot.py`。

## 3. 安装 Python 与依赖库：常规方式

以下命令均在 **PowerShell** 中执行。此节用于新电脑或新环境；已有正常运行的 `.venv` 不要重复重建。

### 3.1 安装 Python

从 [Python 官方 Windows 下载页面](https://www.python.org/downloads/windows/) 获取 Python，选择 3.12 的 64 位运行环境。安装器提供 `Add Python to PATH` 时勾选；如果使用官方安装管理器，则按它的界面安装对应版本。

安装后重新打开 PowerShell，检查：

```powershell
python --version
python -c "import sys; print(sys.executable)"
```

确认显示实际 Python 版本和解释器位置。若只打开 Microsoft Store，或命令无法识别，先处理 Python 安装与 PATH，再继续。

安装了传统 Python Launcher 的电脑也可用 `py -3.12 --version` 检查；下面创建环境时，可用 `py -3.12` 代替 `python`，确保选择的是 3.12。

### 3.2 创建项目虚拟环境

进入项目目录：

```powershell
Set-Location -LiteralPath "G:\山河绘"
```

如果目录带有从其他电脑复制来的 `.venv`，先在文件管理器中将它改名备份，再创建新的环境；不要在任务运行期间移动环境目录。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe --version
```

后续直接调用 `.venv` 内的解释器，通常不必执行激活脚本，也不用修改 PowerShell 执行策略。[Python 官方说明](https://docs.python.org/3.12/library/venv.html)

### 3.3 下载和安装基础库

```powershell
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

`-r requirements.txt` 表示按项目依赖清单下载并安装。当前清单声明：

| 安装名称 | 代码中导入名称 | 用途 |
| --- | --- | --- |
| `numpy>=1.21` | `numpy` | 图像数组、坐标计算、路径处理 |
| `opencv-python>=4.8` | `cv2` | 读图、提线、色区识别和图像处理 |

pip 默认从 Python Package Index 下载包，命令应通过目标环境的 Python 调用，避免装到另一个解释器中。[pip 安装指南](https://pip.pypa.io/en/stable/user_guide/)

### 3.4 安装画稿修订与对照图扩展库

日常 Web 的基础依赖是上面的两个库。运行本项目部分曲线修订、连续铺色、对照图生成脚本时，还需：

```powershell
.\.venv\Scripts\python.exe -m pip install scipy pillow
```

| 安装名称 | 导入名称 | 用途 |
| --- | --- | --- |
| `scipy` | `scipy` | 曲线插值、平滑和几何计算 |
| `pillow` | `PIL` | 生成预览拼图、文字标注和保存图像 |

这两个扩展库目前没有写入项目基础依赖清单，单独执行 `pip install -r requirements.txt` 不会安装它们。Windows 对照图脚本还可能使用系统中文字体，例如 `C:\Windows\Fonts\msyh.ttc`。

### 3.5 检查安装结果

```powershell
.\.venv\Scripts\python.exe -c "import sys, numpy, cv2; print(sys.executable); print('NumPy:', numpy.__version__); print('OpenCV:', cv2.__version__)"
.\.venv\Scripts\python.exe -m pip check
```

安装了扩展库时再检查：

```powershell
.\.venv\Scripts\python.exe -c "import scipy, PIL; print('SciPy:', scipy.__version__); print('Pillow:', PIL.__version__)"
```

能显示版本号、没有 `ModuleNotFoundError`，且 `pip check` 未报告依赖冲突，说明依赖安装通过。

## 4. 可选方式：使用 uv 锁文件安装

需要按项目锁文件重建基础依赖时，可使用 uv；无需同时重复第 3 节的环境创建过程。

安装 uv 的一种方式：

```powershell
winget install --id=astral-sh.uv -e
```

重新打开 PowerShell，执行：

```powershell
uv --version
Set-Location -LiteralPath "G:\山河绘"
uv python install 3.12
uv sync --locked --python 3.12
```

项目含 `uv.lock`，`--locked` 要求按有效的现有锁文件解析，不主动更新锁文件。uv 下载 Python 和依赖可能需要联网。安装方式可参考 [uv 官方安装说明](https://docs.astral.sh/uv/getting-started/installation/)。

需要扩展库时补装到同一个环境：

```powershell
uv pip install --python .\.venv\Scripts\python.exe scipy pillow
```

后续优先直接用 `.\.venv\Scripts\python.exe` 启动。再次同步环境后，检查扩展库是否仍存在；它们未列入当前项目依赖清单。

## 5. 启动 Web 工作台

### 5.1 新电脑推荐：指定解释器启动

在项目目录执行：

```powershell
Set-Location -LiteralPath "G:\山河绘"
$env:PYTHONIOENCODING = "utf-8"
.\.venv\Scripts\python.exe web\server.py --open-browser
```

成功后浏览器打开工作台。保留这个终端窗口，关闭它会停止后台服务。

| 页面 | 地址 |
| --- | --- |
| 绘画工作台 | http://127.0.0.1:8765 |
| 新画稿制作 | http://127.0.0.1:8765/studio |
| 大屏展示 | http://127.0.0.1:8765/screen |

服务默认只监听本机。这些地址应在运行服务的电脑上访问。

### 5.2 双击启动入口

可双击根目录 **启动绘画工作台.bat**。但当前 `web/launch_workbench.ps1` 的解释器选择顺序是：

1. 存在 `D:\Anaconda3\python.exe` 时使用它。
2. 否则使用系统 PATH 中的 `python`。

**这个 Web 启动脚本目前不会优先选择项目 `.venv`。** 如果库安装在 `.venv` 中，双击启动却提示缺少库，请使用 5.1 的明确解释器命令；不要因此反复给其他 Python 安装依赖。

当前启动脚本会检查既有服务和任务状态。任务活跃时优先打开现有页面，不重启后台。作品 JSON 在启动时载入；修订画稿后，应在任务正常退出后重新启动后台加载新版。

### 5.3 首次运行先预演

1. 选一幅作品。
2. 选择 **离线预演**，再点击 **开始绘画**。
3. 查看绘制顺序、黑线、色区和题字；切换参考原图进行比较。
4. 预演完成后再准备实机流程。

页面默认模式是 **机械臂绘画**，首次离线体验时应先切换模式。详细界面说明见根目录 `Web绘画工作台使用说明.md`。

## 6. 配置机械臂与现场环境

只预演时可跳过本节。首次实机、换电脑、换笔、换纸、移动杯子或改变工具姿态时，应重新核对对应现场标定。当前项目里的数值来自现有工位，不应直接当成另一套工位的测量值。

### 6.1 通信与坐标配置

在 `config.py` 中按参数名查找：

| 参数 | 含义 |
| --- | --- |
| `ArmConfig.IP` | 控制器 IP；当前代码为 `192.168.5.1` |
| `ArmConfig.PORT` | 当前驱动使用 Dashboard TCP 端口 `29999` |
| `ArmConfig.USER_INDEX` | 现场测量采用的用户坐标系索引 |
| `ArmConfig.TOOL_INDEX` | 毛笔工具坐标系索引 |
| `ArmConfig.RPY` | 标定与绘画使用的工具姿态 |
| `ArmConfig.PAPER_Z` | 笔尖刚触纸时的基准高度 |
| `ArmConfig.Z_INCREASES_DOWN` | 当前用户坐标系 Z 增大是否表示下压 |
| `CanvasConfig.ROBOT_CORNERS` | 纸张四角坐标，顺序为左上、右上、右下、左下 |
| `ReachConfig` | 允许的运动范围 |
| `PALETTE`、`StationConfig` | 黑墨及相应流程的现场工位设置 |

驱动要求控制器处于相应 TCP/IP 控制模式。通过机械臂控制软件核对网络、控制模式、报警状态、工具与用户坐标系。电脑与控制器应能够在配置的地址互通。

下面只检查 TCP 端口连通性，不发送机器人运动指令：

```powershell
Test-NetConnection -ComputerName 192.168.5.1 -Port 29999
```

地址不同就替换成实际控制器 IP。`TcpTestSucceeded` 为真只代表端口可连，不代表机械臂已完成标定、准备就绪或可立即绘画。当前驱动也会检查端口被其他客户端占用的情况。

### 6.2 Web 参数与根目录配置的区别

Web 页面 **修改参数** 可设置纸面高度、黑墨／蓝色／绿色液面、杯位、蘸取参数和液面下降补偿；网页不控制速度、倍率或加速度。

点击 **保存并检查画稿**，检查通过后保存到 `web/data/site_settings.json`，供下一次网页任务使用。它不会改写 `config.py`、`pigment_measurements.json` 或原画稿。

终端绘画入口仍使用其原配置。Web 参数窗口不能替代纸张四角、工具坐标、用户坐标和姿态标定。实机任务尚未退出时参数窗口只读，暂停也不会解除锁定。

### 6.3 标定命令与作用

以下命令用项目虚拟环境解释器执行。先区分离线检查与实机动作：

| 命令参数 | 作用 | 是否连接／移动机械臂 |
| --- | --- | --- |
| `main.py --check` | 配置自检 | 不连接机械臂 |
| `main.py --probe` | 画布四角及中心空跑 | 会连接并移动 |
| `main.py --calibrate-z` | 交互标定纸面高度 | 实机标定，会连接并移动 |
| `main.py --calibrate-ink` | 交互标定黑墨液面 | 实机标定，会连接并移动 |
| `main.py --teach` | 现场示教流程 | 涉及机械臂现场操作 |
| `main.py --test-strokes` | 笔宽标定试线 | 会连接并实际落笔 |

先执行不运动的配置检查：

```powershell
.\.venv\Scripts\python.exe main.py --check
```

其他命令应在现场布置与操作条件确认后分别执行。出现画稿与标定不一致时，应核对新工位并重新生成或检查画稿，不要通过恢复旧工位数值强行通过。

## 7. 画稿检查、制作与实机作画

### 7.1 当前执行画稿在哪里

五幅作品的执行源位于：

```text
待画作品/
  01_松瀑亭舟_横题山河绘/任务资料/painting.json
  02_松岸曲水_竖题山河绘_绘字修复版/任务资料/painting.json
  03_云山亭阶_横题山河绘/任务资料/painting.json
  04_柳岸渔舟_横题山河绘_净山岛新版/任务资料/painting.json
  05_青绿梯田云山_横题山河绘/任务资料/painting.json
```

Web 不再以旧 `输出`、`展示选画` 或 `已确认` 目录作为这五幅图的执行来源。只替换 PNG 预览不会改变机械臂路径，需要使用对应的执行 JSON。

单幅离线检查示例：

```powershell
.\.venv\Scripts\python.exe run_json_painting.py --job "待画作品\01_松瀑亭舟_横题山河绘\任务资料\painting.json" --check
```

若提示速度或当前配置不一致，优先使用 Web 的 **保存并检查画稿** 流程，以检查本次网页现场参数下的执行副本；终端检查和网页检查使用的参数来源可能不同。

### 7.2 从图片制作新画稿

1. 在工作台点击 **制作新画稿**。
2. 上传 PNG、JPG 或 WEBP，文件小于 20 MB。
3. 提取勾勒线稿，对照原图整理轮廓、短线和顺序。
4. 选择蓝、绿颜料，调整铺色间距、方向和下压量，生成上色路径。
5. 查看合成预览并逐笔预演。
6. 点击 **检查可执行画稿**。
7. 通过后点击 **加入画库并进入工作台**。

制作和加入画库不会自动启动机械臂。草稿位于 `web/data/studio`；新发布作品位于 `待画作品/新作品`。

### 7.3 正常实机绘画

1. 放好纸张和毛笔，核对黑墨、颜料及现场参数。
2. 选择作品和 **机械臂绘画** 模式。
3. 点击 **开始绘画**，完成准备确认。
4. 黑线结束后等待墨干，洗笔、擦拭并准备对应颜色。
5. 点击 **已洗笔，开始蓝色／绿色**，一色完成后按提示准备下一色。
6. 上色全部完成后洗笔、准备黑墨，最后写题字。
7. 完成后取下作品、清洗毛笔；可保存当前画布或打开大屏。

网页进度来自已确认完成的笔触，实时画布从空白逐笔显示。当前五幅含连续铺色路径，单笔可能比以前更长，暂停会等当前笔完成后停靠。需要立即停止时使用控制器停止或急停。

### 7.4 暂停、结束与记录

- **暂停／继续**：在本次任务内从下一笔继续。
- **结束作画**：停靠或等待时结束；网页不保存跨重启续画进度，再开始会从第一笔画起，须换新纸。
- **清空之前作画记录**：任务退出且现场确认后清空画布、归档旧记录；它不会停止或移动机械臂。
- **关闭浏览器**：不会停止机械臂。
- **关闭后台**：会中断本次同步，不能自动续画。

终端入口有独立的进度保存与续画流程，不应与网页的内存任务混用。终端日常入口可双击 **启动菜单.bat**，或运行：

```powershell
.\.venv\Scripts\python.exe launcher.py
```

## 8. 更换电脑、备份与更新

迁移前正常结束任务，保存需要的资料。推荐保留：

| 内容 | 处理方式 |
| --- | --- |
| 源码、依赖清单、`uv.lock`、`web`、`scripts` | 完整复制 |
| `待画作品` | 完整复制，保留原图、执行 JSON 和历史版本 |
| `config.py`、`pigment_measurements.json` | 备份原值，新工位逐项重新核对 |
| `web/data/site_settings.json` | 作为旧工位记录保留，新现场重新测量 |
| `web/data/studio` | 需要保留未完成草稿时复制 |
| `robot_runs` | 留作执行与异常记录备查，不作为新工位直接续画的依据 |
| `.venv` | 在新电脑重新创建并安装依赖 |

更新依赖、代码或画稿应在任务退出后进行。更新后重新执行依赖检查、配置检查和离线预演。固定可用环境时可导出版本清单：

```powershell
.\.venv\Scripts\python.exe -m pip freeze > requirements-local.txt
```

此清单记录本机实际版本；跨平台迁移还需确认包的兼容性。

## 9. 常见安装与运行问题

| 现象 | 原因与处理 |
| --- | --- |
| `python` 无法识别或打开 Microsoft Store | Python 未安装、PATH 未生效或命中了应用别名；检查安装，重新打开终端，确认解释器路径 |
| `No module named cv2` | 在目标环境运行 `python.exe -m pip install -r requirements.txt`；安装名是 `opencv-python` |
| `No module named numpy` | 基础依赖未安装，或正在使用另一个 Python |
| `No module named scipy`／`PIL` | 修订脚本扩展依赖未安装；使用目标解释器安装 `scipy pillow` |
| 安装成功但双击仍报缺库 | Web 启动脚本选中了 Anaconda／系统 Python；按 5.1 指定 `.venv` 启动 |
| pip 下载超时 | 检查能否访问 PyPI、网络和代理设置后重试；不要反复新建环境 |
| 找不到 `requirements.txt` 或 `web/server.py` | 当前目录不对；先进入含这些文件的项目根目录 |
| `.venv` 的 Python 无法启动 | 环境来自其他电脑或旧路径；备份后在本机重新创建 |
| `uv` 无法识别 | 安装 uv 并重开终端，或直接使用第 3 节的 pip 方式 |
| `uv sync --locked` 失败 | 查看锁文件、Python 版本及下载错误；不要直接删除锁文件来掩盖问题 |
| 端口 8765 已占用 | 检查是否已有本项目工作台；不要同时启动多个后台。任务退出后再处理服务 |
| 五幅图缺失或显示无法读取 | 检查 `待画作品` 是否完整、各 `painting.json` 是否存在并可解析 |
| 保存参数失败或报标定不一致 | 核对纸张四角、工具、姿态、液面与现场测量；依赖安装不能修复标定问题 |
| 机械臂连接失败 | 核对 IP、电脑网络、TCP/IP 控制模式及端口占用；查看控制器状态 |
| 文件路径乱码 | 使用 PowerShell、带引号的路径及 UTF-8 终端；可先设置 `PYTHONIOENCODING=utf-8` |

需要临时使用其他 Web 端口时，服务支持：

```powershell
.\.venv\Scripts\python.exe web\server.py --port 8766 --open-browser
```

这时访问 `http://127.0.0.1:8766`；双击启动脚本仍默认使用 8765。改变端口前先确认没有活跃任务。

## 10. 从零开始的最短操作清单

前提：已安装 Python 3.12，已解压完整项目，当前是尚未建环境的新安装。

```powershell
Set-Location -LiteralPath "G:\山河绘"
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip install scipy pillow
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe main.py --check
$env:PYTHONIOENCODING = "utf-8"
.\.venv\Scripts\python.exe web\server.py --open-browser
```

打开页面后先选择 **离线预演**。实机绘画前，按第 6 节完成当前工位配置和测量。

# 山河绘文件保留与清理说明

按“保留原来五幅图能正常实绘”的要求，于2026年10月20日完成清理。

清理前约 **14.95 GiB**，本轮实际删除 **14,082 个文件、13.87 GiB**，剩余约 **1.08 GiB**。不同界面采用GB或GiB时显示值会不同。

| 文件或目录 | 删除内容与依据 |

| `archive/` | 历史代码、旧环境和旧画稿备份，当前五幅从“待画作品”直接读取 |
| `输出/` | 旧生成批次、重复计划与预览，当前五幅完整画稿不在这里 |

| `artifacts/`大部分历史子目录 | 旧调试、色面实验、比较报告、40页旧PPT与PPT构建预览等；保留16页最终PPT、技术介绍文档及少量参考材料 |
| `.venv/`、`.展示运行环境/` | 两套旧解释器实际启动均失败；当前工作台使用已验证的`D:\Anaconda3\python.exe` |

| 各层`__pycache__/`、`.pytest_cache/`、网页旧服务日志 | 可再生成的缓存和已退出服务的历史日志 |

## 两处非运动调整

1. `web/catalog.py`移除第六幅登记，原来五幅的目录、标题与顺序不变。
2. `启动菜单.bat`优先使用已验证的`D:\Anaconda3\python.exe`，避免删除失效旧环境后尝试重新创建环境。网页原启动方式不变。

修改前副本位于`维护记录/清理_20261020/`。没有改变速度、下压、笔触、标定和阶段顺序。

## 清理后验证

使用实际工作台的Python环境，禁止网络连接并拦截机械臂对象创建。五幅均完成离线参数/轨迹校验和勾勒、蓝色、绿色、题字的模拟调度。

清理前后五幅画稿文件SHA256和执行清单SHA256完全相同；另有 **1529个受保护文件**逐个复核未变。网页画库只加载原来五幅，读取错误为零。未启动或移动机械臂，不能把离线检查称为重新实机试画。

附加运行了21项阶段与现场设置回归测试，其中20项通过。旧集成测试仍按固定2.4倍计算上色速度，当前五幅已有“2.4×画稿倍率2.0”的配置，因此该旧速度断言失败。速度相关源码与五幅画稿均在本轮受保护校验中保持不变；本次没有修改绘画参数迁就旧测试。五幅专用的前后执行清单对比与四阶段模拟全部通过。

第一幅保留的是暂停生命周期状态，其中`resumable=false`，不能将该标记理解为已保存逐笔续画进度。状态文件与任务缓存均未删除。

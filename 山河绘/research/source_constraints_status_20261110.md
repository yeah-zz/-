# 原图约束读取：改动、实际效果与未通过项

本轮修改了提取算法，结果更贴原图，但完整笔触恢复仍未通过，未采用为绘画版本。没有训练新神经网络权重，也没有连接机械臂。

## 实际改动

1. 绕开已失败的直接坐标预测：从输入图像的局部暗线、双侧亮度差和多尺度脊线读取墨带，不输入人工曲线、角色、端点或参考笔数。
2. 对粗墨区域增加多尺度 Hessian 法线方向非极大值抑制，减少将宽墨带内部孔洞读成网状骨架的情况。第一轮墨带骨架结果也单独保留，未隐藏失败尝试。
3. 图上边每条只追踪一次；仅在同一交汇处存在明确方向优势时延续。对线带中心采样造成的小断口，仅在整条连接都处于检测到的墨带内、两端互相唯一优选时续接；不跨白缝，不强接并行线或竞争分支。
4. 短段与交汇仍保留待定；没有用硬性笔数上限或批量删短线制造改善。孤立脊线点不作为可画曲线，输出也不是原图全部墨迹的无损表示。

这是图像处理与路径读取的算法候选，不是“已学会皴法”的新模型。角色、对象分组、真实分笔、原始行笔方向尚未学会。

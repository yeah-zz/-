# 上色下压对照测试

在 VS Code 打开 `E:\山河绘`，使用终端运行：

```powershell
python test_color_pressure_03.py --execute
```

默认蓝色。测试绿色时：

```powershell
python test_color_pressure_03.py --execute --color green
```

先结束网页里的绘画任务，在原标定位置放好新纸。脚本读取网页已保存的纸面高度、对应颜料杯和运动参数；显示测试坐标、落笔Z及预览位置后，输入 `RUN` 才会连接并执行。

左块下压0.2mm，右块0.3mm（这里左右指机器人用户坐标的+X方向）。每块20×5mm，6条水平往返排列的独立短笔，中心笔距1mm；两块间留12mm，总范围52×5mm。默认放在标定画布中央，可在提示中输入其他起点X Y。开始和换块时自动蘸同一杯颜料；超时或暂停继续可能额外补蘸。保持同一支笔和同一杯颜料，中途不要加水，便于比较覆盖、白缝及洇色。

只看预览，不连接机械臂：

```powershell
python test_color_pressure_03.py
```

按P在当前笔结束后暂停，再按提示C继续或Q退出。测试不修改正式画稿、网页下压值或标定文件；未提供断点续画。每次执行请使用空白测试区。

若终端的Python缺少项目依赖，选用运行本项目所用的Python解释器。

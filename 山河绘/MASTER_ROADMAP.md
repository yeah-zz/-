# 山河绘算法研发总纲

2026-11-24 起以传统山水画的数字理解、技法学习和自主绘画为研发范围。验收终点是从空白数字画布出发，生成可追溯、可评价和可修改的国画笔触序列。涵盖逐笔临摹及同风格新构图创作。

实体机械臂控制、压力与接触力、实体视觉与坐标标定、实体毛笔动力学、MPPI、颜料混合、洗笔及实体画布反馈暂缓，既有相关代码继续归档。数字毛笔、设色和直接读取数字画布的反馈参与算法验收。数字含水量及虚拟提按属于渲染参数。

## 双线执行

- A 线从多源视觉结构发现入手，融合暗墨、亮脊、双侧轮廓、内部色带和整图语义。随后推进树石细粒度语义、实例、遮挡、拓扑及基于笔形和笔组的皴法辨识。
- B 线以可核查的标准技法、教学示范及复核对象参考开展树木、山石和皴法专项试验，并推进笔触表示、数字毛笔、风格学习、逐笔绘画及数字反馈。
- 两线并行。B 线可用有来源的样本开展受控绘画学习。由 A 线自动发现的对象、结构及笔迹通过独立验证后再接入。手工布局、样本拟合和模型输出分别记录。

## G0 至 G9

| 阶段 | 实施内容与验证 |
| --- | --- |
| G0 数据与分组 | 建立整画、树石、皴法和笔触样本。按作品隔离训练、开发与独立测试，核查来源和重复，区分粗标、精标、伪标签及合成。 |
| G1 技法辨识 | 先做披麻、斧劈与混合／未知，再扩展解索、卷云、牛毛、雨点、米点、折带，以及勾、皴、擦、点、染。分别验证类别、笔形、笔组和结构关系。 |
| G2 语义与实例 | 发现多源候选，区分树冠、枝干、树根、岩面、轮廓、皴纹、点苔与设色。分别验证几何交汇、语义、同实例、遮挡和真实连接。 |
| G3 树木专项 | 学习主干、根、分枝和叶群。按松、柳、枯树、杂树及鹿角、蟹爪、点叶、夹叶等扩展。分别验收临摹和新形态。 |
| G4 山石专项 | 学习山石结构、岩面和皴笔走向，在新石面上验证技法迁移。观察方向、长度、宽窄、疏密、层叠与留白。 |
| G5 笔触与数字毛笔 | 统一对象、角色、技法、曲线与宽度、浓淡设色、虚拟提按、干湿飞白、顺序、来源及置信。验证渲染、存取和逐笔可追溯。 |
| G6 笔触重建 | 研究曲线拟合、区域分解、可微渲染和逆向优化，比较墨迹、结构和笔法误差。静态推断的顺序单独标记。 |
| G7 风格学习 | 区分内容与构图、形态、笔组、墨色、设色和留白等风格特征，转成可调用参数或学习表示。 |
| G8 整幅数字绘画 | 模式 A 从原作逐笔临摹。模式 B 从参考学习风格并生成新构图。两种最终图都能从空白画布重放。 |
| G9 数字反馈 | 读取数字画布，定位图像、结构、技法和风格偏差，优化笔触及顺序，设置停止条件并检查迭代收益。 |

历史 G1–G3 与本纲对应同编号。历史 G4 的整幅提取、创作及执行分别迁入 G5–G9，硬件部分归档。历史 P1–P3 对应 G0–G2、G6，P4 对应可选规划工程，P5 对应 G3，P6 对应 G7–G9，P7 暂缓。

## 验收与回归

每轮落实资料核查、代码、实跑、对照、可视化、失败分析和基线回归。分别报告候选覆盖、对象与连接准确性、待核比例、生成和渲染质量。独立验收按作品和作者分组，先标注后推理，先冻结后测试。接入顺序为独立验证、整幅数字绘画回归、局部接入和逐步推广。已认可的 500 笔和 489 笔工作基线按哈希保留。

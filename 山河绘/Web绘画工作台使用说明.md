# 山河绘 Web 绘画工作台使用说明


> **新增入口：名家笔触实验室（8770）**  
> 双击根目录 `启动名家笔触工坊.bat`，或在 8765 工作台左侧点击“名家笔触”。先选名家与母题，生成 2–6 幅预览，选定后导出 `painting.json`。导出只生成画稿，不连接机械臂；仍需回到本工作台核对纸张、杯位和现场参数后开始。详见 `master_studio/README.md`。

适用版本：2026 年 10 月 7 日的本地工作台。面向选画、制作画稿和操作机械臂的使用者；实际作品、笔数与任务状态以当前页面为准。

## 1. 打开工作台

1. 在项目目录双击 **启动绘画工作台.bat**。
2. 等待服务启动和浏览器打开，进入绘画工作台。
3. 作画期间保持后台服务运行。

常用入口：

| 页面 | 地址 | 用途 |
| --- | --- | --- |
| 绘画工作台 | http://127.0.0.1:8765 | 选择作品、预演、控制作画 |
| 新画稿制作 | http://127.0.0.1:8765/studio | 上传原图、整理黑线、规划颜色 |
| 大屏展示 | http://127.0.0.1:8765/screen | 展示当前任务与画布 |

这些是本机地址，请在运行工作台的电脑上打开。

## 2. 第一次使用：先看一遍离线预演

1. 在 **待画作品** 中选择一幅画。
2. 在任务面板选择 **离线预演**。
3. 点击 **开始绘画**，观察黑线、上色和题字的顺序。
4. 按页面提示继续各阶段；需要加快播放时选择 **1×、4×、12×**。
5. 使用画布上方的图片按钮查看参考原图，再切回实时画布进行比较。

离线预演使用画稿中的实际笔触，不驱动机械臂。播放速度只改变预演速度。

预演用于检查形状、笔触顺序和色区。纸上的线宽、颜色深浅与渗色还受毛笔、含水量、颜料和纸张影响，页面效果是估计值。

## 3. 看懂工作台

| 页面内容或按钮 | 作用 |
| --- | --- |
| 待画作品／全部画作 | 选择要画的作品 |
| 制作新画稿 | 打开图片转画稿的制作页面 |
| 实时画布 | 展示当前任务已经完成的笔触 |
| 查看参考原图 | 查看作品对应的原图 |
| 已绘制 X / Y 笔 | 当前完成笔数与总笔数 |
| 黑线勾勒／淡彩上色／最后题字 | 显示各阶段进度；有题字的任务会显示题字阶段 |
| 任务动态 | 查看执行、等待、换色和错误提示 |
| 修改参数 | 设置下一次实机任务使用的现场参数 |
| 保存当前画布 | 下载当前画布图像；未画完时保存的是部分画面 |
| 大屏模式 | 展示同一个任务，不会另开一次作画 |

选择作品后，实时画布可能是空白的。开始任务后才会逐笔显示；要先看完整原图，请使用 **查看参考原图**。

## 4. 开始机械臂绘画

### 4.1 开始前

1. 选择作品，核对标题、参考原图、纸张尺寸与笔数。
2. 放好并固定纸张，确认毛笔、黑墨和所需颜料已准备好。
3. 核对纸面标定、杯位和工具设置，确保机械臂活动空间合适。
4. 如果换了笔、移动了杯子或改变了纸面高度，先完成对应标定并更新现场参数。
5. 选择 **机械臂绘画**，点击 **开始绘画**。
6. 在准备确认框中勾选准备完成，再点击 **开始绘画**。

后台检查通过后才启动执行。机械臂每确认完成一笔，网页画布添加对应的一笔；进度不是按播放时间估算。

### 4.2 黑线完成后洗笔、换色

典型流程：**黑线勾勒 → 洗笔并上第一种颜色 → 洗笔并上下一种颜色 → 准备黑墨 → 最后题字**。

1. 黑线阶段结束后，机械臂停靠并等待。
2. 等墨干，洗净并擦拭毛笔，准备页面提示的颜料。
3. 点击 **已洗笔，开始蓝色** 或 **已洗笔，开始绿色**，按当前任务可用选项继续。
4. 一种颜色完整画完后，按新的提示再次洗笔、换色。
5. 有题字的任务完成上色后，再洗笔并准备黑墨，点击 **已洗笔，准备黑墨写题字**。
6. 全部完成后取下作品、清洗毛笔。

换色确认表示现场准备已经完成，应在洗笔和颜料准备完成后点击。

## 5. 暂停、继续、结束与清空

| 操作 | 实际行为 | 后续处理 |
| --- | --- | --- |
| 暂停作画 | 等当前笔完成后抬笔停靠 | 等页面显示已暂停，再处理现场 |
| 继续作画 | 在当前任务中接着下一笔执行 | 核对现场条件后继续 |
| 结束作画 | 在停靠或等待状态结束本次任务 | 再次开始会从第一笔画起 |
| 清空之前作画记录 | 清空网页画布与旧记录，将旧记录归档 | 保留画稿和现场参数；新任务使用新纸 |

**网页暂停需要等待当前笔完成。需要立即停止时，使用机械臂控制器停止或急停。**

当前网页版任务不保存可跨重启续画的进度。同一任务暂停后可以继续；结束任务或重启后台后，不要按原纸上的进度直接重新开始。

清空记录不会停止或移动机械臂。操作前须结束绘画程序，确认机械臂停止、旧指令队列取消、毛笔离纸；任务仍活跃时页面会拒绝清空。清空后换新纸，从第一笔开始。

关闭浏览器不会停止机械臂。后台仍运行时重新打开页面可查看当前任务；关闭或重启后台会中断同步，不能据此认为机械臂已经停止。

## 6. 修改现场参数

在工作台点击 **修改参数**。所有高度和位置填写现场实测值，单位为毫米，保留示教器读数的正负号。

### 6.1 纸面、液面与杯位

| 参数 | 含义 |
| --- | --- |
| 纸面基准高度 | 当前毛笔笔尖刚接触纸面时的 Z 高度 |
| 黑墨／蓝色／绿色液面高度 | 笔尖刚接触相应液面的 Z 高度 |
| 杯中心 X、Y | 对应杯子的实际中心位置 |
| 杯口高度 | 杯口位置，用于蘸色路径检查 |
| 蘸入深度 | 笔尖进入液面的深度 |
| 停留／沥液时间 | 蘸色停留和离杯后沥液的时间 |

杯位和蘸色参数位于 **杯位与蘸色参数** 展开项。网页不会测量现场高度；移动纸张、改变纸角位置、工具坐标或毛笔朝向时，还需完成对应标定。

### 6.2 液面下降补偿与运动设置

参数面板可分别设置黑墨、蓝色和绿色的补偿开关、累计行笔长度、每次额外下降及累计上限。当前默认每累计画500毫米，下次蘸取下降0.1毫米，累计最多0.5毫米。

网页不再修改机械臂速度、倍率或加速度，执行沿用原画稿和原程序设置。旧网页速度/加速度字段不会参与新任务。**1×、4×、12×** 只用于离线预演播放。

### 6.3 保存并检查

1. 输入参数，点击 **保存并检查画稿**。
2. 等待离线检查结果；检查不连接或移动机械臂。
3. 全部检查通过后保存；失败时根据提示修正，旧参数保留。
4. 回到工作台，启动新任务。

实机任务或洗笔任务运行期间，参数编辑会锁定，暂停状态也不能修改。每次新任务使用启动时确定的一份参数。

更新纸面高度会调整执行时的绝对 Z 高度；不会改变画作构图、笔数、逐点下压量或上色规划。

## 7. 下压量、笔宽与颜色覆盖率

**下压量** 是笔尖相对刚触纸位置继续下压的距离。例如 **0.15 mm** 表示下压位移，不能直接解释成纸上线宽为 0.15 mm。实际线宽需用当前毛笔和纸张试画测量。

**铺色间距** 是规划中相邻铺色路径的间隔。间距减小通常会增加上色笔数、减小路径之间的空白；实际能否覆盖还取决于有效笔宽、色区识别和路径边界。

**预览浓淡** 改变制作页面显示的颜色透明度。它不等于真实颜料浓度，也不能通过调深预览来补上缺失路径。

如果预览上色仍有较大空隙：

1. 切到 **上色路径**，检查目标区域是否生成了路径。
2. 整个区域没路径时，检查原图和颜色选择，仅调整浓淡不能解决。
3. 区域有路径但排列疏时，调整铺色间距并重新生成。
4. 对比 **合成预览** 和 **参考原图**，检查是否越界、遗漏或盖住需要保留的细节。
5. 用实物试画校准有效笔宽、含水量和颜料深浅，再判断纸上的覆盖效果。

## 8. 制作一幅新画稿

点击 **制作新画稿**，按四步完成。制作过程不会自动启动机械臂。

### 第一步：选择参考图

1. 上传 PNG、JPG 或 WEBP，文件小于 20 MB。
2. 输入画作名称，点击 **保存名称**。
3. 点击 **提取勾勒线稿**。

浅底、轮廓清楚的山水或线稿更容易提取。复杂照片和纹理较多的图片需要更多人工检查。

### 第二步：整理勾勒

1. 在 **参考原图** 和 **勾勒路径** 之间切换，检查轮廓。
2. 使用 **过滤短线** 去除零碎短线，使用 **勾勒笔压倍率** 调整下压量。
3. 选择整体笔触顺序，点击 **按参数重新整理**。
4. 点击画布或笔触列表中的一笔，使用 **上移一笔／下移一笔／移除选中笔触** 调整。
5. 只画黑线时点击 **仅生成黑色勾勒**；需要颜色时点击 **接着规划上色**。

重新整理会从原始提线结果重新处理。建议先完成整体参数调整，再删改个别笔触；过滤短线可能同时去掉树梢等有用细节，应对照原图确认。

### 第三步：规划上色

1. 选择现场可用的蓝、绿颜料。
2. 设置 **铺色间距、铺色方向、上色下压量、预览浓淡**；方向 0° 为横向。
3. 点击 **生成上色路径**。
4. 查看 **上色路径** 和 **合成预览**，检查覆盖范围与原图是否贴合。
5. 根据需要调整颜色顺序、同色笔触顺序，或移除不合适的笔触。
6. 点击 **逐笔预演** 查看完整绘制过程。

不选颜色可生成纯勾勒画稿。修改勾勒后需重新生成上色并重新检查。

### 第四步：检查并加入画库

1. 点击 **检查最终画稿** 进入最后一步。
2. 核对黑线笔数、上色笔数及预览。
3. 点击 **检查可执行画稿**。
4. 检查通过后点击 **加入画库并进入工作台**。
5. 在工作台重新核对现场参数，按正常流程确认开始绘画。

加入画库只保存作品，不启动机械臂。已有作品保留；发布后继续修改草稿也不会自动覆盖已加入画库的版本。

不需要当前草稿时可点击 **放弃创作**，确认后返回选择图片；已经加入画库的作品仍保留。

## 9. 笔数、画布保存与展示

- 制作页分别显示勾勒与上色笔数，工作台显示当前作品总笔数和已完成笔数。
- 修改提线、铺色间距或删改笔触后，笔数可能变化，请重新检查最终画稿。
- 一笔按画稿中的一条笔触计数，不等于线段数、采样点数或蘸墨次数。
- **保存当前画布** 保存当前显示进度。需要完整预览时先完成离线预演；需要实物记录时另拍纸面照片。
- **大屏模式** 展示当前任务，适合外接显示器观看作画过程。

## 10. 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 网页打不开或提示服务无法连接 | 检查启动程序是否仍在运行，核对本机地址。实机作画期间先核查任务与机械臂状态，再决定是否重启后台 |
| 选完作品画布是空白 | 实时画布等待第一笔完成；点击图片按钮查看参考原图，或先运行离线预演 |
| 修改参数按钮或输入框不可用 | 当前实机或洗笔任务可能仍活跃。任务结束后再编辑；暂停不会解除锁定 |
| 提示洗笔，进度不再增加 | 这是阶段等待。洗净毛笔、准备正确颜料后，点击对应颜色确认按钮 |
| 点暂停后仍在画 | 当前笔需要完成后才停靠。立即停止使用控制器停止或急停 |
| 预览颜色稀疏或不贴合 | 检查上色路径、颜色选择、色区和铺色间距，重新生成并对比原图 |
| 实物线宽与预览不同 | 用当前笔、纸和颜料试画校准；下压量不等于线宽 |
| 清空记录被拒绝 | 先结束活跃任务并核查现场。清空记录不能代替停止机械臂 |
| 执行失败或显示需现场核查 | 查看任务动态，核对机械臂位置和最后实际完成的笔。确认状态前不要重复点击开始 |
| 制作页面提示需要更新后台 | 等当前任务退出并确认现场状态后再重新启动后台，然后打开制作入口 |

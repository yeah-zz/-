# 淡墨短断口逐截面复核

## 推进目标

补齐圆石弧线和岩层横线的短淡墨断口，减少轮廓碎裂，并检查相邻纸纹及留白。

## 实际新增

沿笔迹逐个检查原图横截面，要求中心附近存在灰度低于两侧的墨带。允许候选落在距墨带中心一像素处，以容纳弧线或浅墨边缘的轻微偏移。路径仍受两端同类墨迹、连续原图支持和最多六个像素的约束。

| 检查项 | 原双端续接 | 增加逐截面复核 |
| --- | ---: | ---: |
| 已知淡线参考 | 15 / 22 | 22 / 22 |
| 圆石弧线 | 0 / 4 | 4 / 4 |
| 岩层横线 | 0 / 3 | 3 / 3 |
| 既有纸纹误补 | 0 / 20 | 0 / 20 |
| 三件留出作品的可见墨线参考 | 31 / 31 | 31 / 31 |

四块预标纸面也没有新增预测墨迹。旧案例总计新增九个补点，其中七个有原图墨线参考，另两个处于归属待核的位置。

## 仍有失败

旧案例的一个浓墨参考点原本就未进入方向筛选候选，仍无法由本模块恢复。覆盖数字统计的是预标像素，完整笔画质量仍需整段验收。三件新作品的裁片里没有触发新规则的额外补点。后续留出测试应优先覆盖旧规则仍漏、且有双端可见墨迹的自然断口，并评估两端附近的真实纸纹。

## 独立验证

按原图预标后，运行三件归档作品裁片的冻结测试。这些素材此前未用于本规则调参。三图的 31 个墨线参考集中在一件作品的五个局部，冻结对照无增益，候选尚未达到独立接入条件。47 项相关单元测试通过。500 笔认可版和 489 笔工作版哈希核验通过，机械臂离线。

# 2026-11-23 浅色树干与岩纹的原图复核

## 推进目标

推进 G2 树石区分。核查上一轮双侧墨脊规则挡下的位置，确认哪些是浅树干、哪些是岩纹或坡边，并比较短程放宽和连续树干颜色两种补回方法。G1 同时复查了三个皴法归属冲突的原图上下文。

## 实际新增

从 14 张归档图中整理 18 处被严格规则拦下的候选。粗标只用于筛选位置，再看原图与上下文。九处完成了助手区域复核，包含两段浅色树干、一处树群、一处岩纹、一处坡边和四处边界待定。其中两组在同一幅画里同时包含浅树干和近邻坡边或点状墨迹，适合后续检验对象归属。它们是区域参考，单个像素的归属仍可能不同。

用冻结模型对 26 张归档裁片跑完两组新对照。在同一批 14 张图中，三个短断口方案都保住了此前已恢复的枝梢。相对双侧墨脊方案，各试验的额外变化如下。

| 方案 | 额外恢复的粗标树木像素 | 额外误作树的粗标岩面像素 |
| --- | ---: | ---: |
| 前后双侧墨脊支持，只放宽一个像素 | 0 | 56 |
| 前后双侧墨脊支持，允许两个像素 | 0 | 97 |
| 单像素弱段允许小转折 | 2 | 114 |
| 只从连续细长树区补回 | 278 | 1,433 |
| 连续细长树区加邻近色度一致性 | 249 | 1,207 |

两个浅树干参考中，原先被挡下的候选区域分别为 46 和 37 像素。新增颜色约束在这两个区域均无补回，仍把 R2 坡边处的 13 个像素归为树。当前结果支持把有填色的宽树干及两侧轮廓作为整体来核查。

皴法方面，原图显示暂定披麻框内同时可见山面纹理和深色团块。另有一框涉及淡色树干及附近墨迹，一框位于明显叶丛。三处均保留待核，树根附近的暗点未据此标作点苔。

## 仍有失败

短断口规则可在受控直线和转折中通过，实图上增益很小。颜色可以挡掉一部分误补，也会挡掉部分树区，尚不能单独判断树干与相邻着色岩面。两组新候选均未接入。

## 独立验证

尚未通过。复测仍使用历史归档。九处区域为助手原图复核，尚缺按整笔确认的分支连接和边界参考。合成检查覆盖单点、两点、小转折、分离墨迹及颜色匹配。已核验 500 笔和 489 笔基线，机械臂离线。

下一步将两段浅树干的双侧轮廓与内部淡色分开标记，再按整段检查树干是否被识别出来，同时保住附近岩纹、叶簇和地面留白。

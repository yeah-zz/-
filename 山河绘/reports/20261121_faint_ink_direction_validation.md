# 淡线方向约束的跨图留出检查 · 2026-11-21

## 推进目标

冻结方向约束，在三张此前未用于该规则的新图上，检验淡线续接和方向性纸纹的误提。

## 实际新增

先从原图确定两段淡线、四处纸面参考和一个受控短断口，再运行冻结模型。三个输入都是项目现有资料，本轮用于淡线规则的留出检查。纸面包括笔锋附近留白、山脊外侧留白、山面旁纸纹和开阔纸纹。

| 检查 | 补线基线 | 直接续接 | 方向筛选 |
| --- | ---: | ---: | ---: |
| 笔锋渐淡段覆盖列数 | 43／43 | 43／43 | 43／43 |
| 淡山脊覆盖列数 | 31／31 | 31／31 | 31／31 |
| 深浅不同的四个纸面参考区新增墨迹 | 0 | 0 | 0 |
| 三张自然图全图新增墨迹 | 0 | 112 | 21 |
| 受控短断口恢复列数 | 0／4 | 4／4 | 4／4 |

自然图的目标淡线在冻结基线中本来已覆盖。受控输入先移除笔锋中心参考带的12个预测墨迹像素，方向筛选补回4个中心线像素，覆盖被移除的4列。随后把同一处遮挡扩宽，删去该范围的41个模型墨迹像素，方向筛选依然补回中心带的4列。扩宽遮挡是同图补充复核。两次都测的是中心线能否续上，原墨带宽度没有完整恢复。

## 仍有失败

三张自然图中，仍保留21个新预测墨迹像素，11组已全部放大。浅纸纹图中部分补点位于规则的方向性细纹上，未找到清晰连续的手绘墨迹支持，归属暂未确认。四个事先标注纸面区没有新增误提，冻结模型对其中一部分纸面已有误分，续接规则没有修复原误分。

自然淡线参考都没有触发漏线恢复，本轮尚未检验新作品中真正漏提的长淡线。下一步应优先固定自然漏线与纸纹贴邻墨迹的实图，分别检验。候选暂未接入正式提取。

## 独立验证

完成三张新图的冻结规则留出测试，参考未经独立阅标，整笔淡线恢复验收尚未完成。35项相关单元测试通过。500笔认可版与489笔工作版哈希核验通过，机械臂离线。

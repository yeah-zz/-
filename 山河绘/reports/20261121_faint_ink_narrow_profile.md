# 暖色淡横线｜细截面复核与候选补充

## 推进目标

查明暖色淡横线在候选生成和逐截面复核中漏掉的位置，尽量恢复可辨墨线，同时控制近邻纸面上的新增补点。

## 实际新增

增加近距离横截面取样，以免两三个像素外的深墨压低细线的对比。分别比较仅复核现有候选和允许在相邻位置补充候选。两版均保留原图墨带两端支持、方向一致性和周期网纹检查。

| 检查项 | 上轮设色方案 | 仅细截面复核 | 加候选补充 |
| --- | ---: | ---: | ---: |
| 暖色淡横线原固定中心 | 7 / 15 | 12 / 15 | 13 / 15 |
| 暖色淡横线两端连通 | 否 | 否 | 否 |
| 三段已接通墨线回归 | 3 / 3 | 3 / 3 | 3 / 3 |
| 固定底材参考新增误补 | 0 / 41 | 0 / 41 | 0 / 41 |
| 受检整幅裁片新增像素 | 0 | 18 | 31 |

原来已生成的 6 个漏点找回 5 个。原来未生成的 2 个漏点中找回 1 个。剩下的左端位置在原图上的近邻对比仅约 3 个灰度级。另一处固定中心的上方一像素存在更暗的墨迹，固定中心本身未通过细截面证据。评分位置保持原样。

## 仍有失败

暖色横线未按锁定参考整段接通。加候选补充后的 31 个新增点中，6 个落在目标横线上，其余 25 个在其他区域。已输出这些位置的原图局部，其中可见印刷纹理与树石边缘的疑似误补，仍需逐点确认。固定底材参考未增加误补，不能由此估计所有新增点的准确率。

## 独立验证

本轮用已知案例比较两个阶段的效果，独立接入验收待做。56 项相关单元测试通过。500 笔认可版和 489 笔工作版的哈希核验通过，候选暂未接入，机械臂离线。

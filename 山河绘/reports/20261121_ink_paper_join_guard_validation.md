# 灰墨保护规则留出检查 · 2026-11-21

## 推进目标

冻结最新的灰墨保护规则，在此前未用于规则调试的原图上，检查真实纸缝、逐渐汇合的墨线与深墨面。

## 实际新增

在三张已有项目原图中先固定六处参考，再运行冻结模型、限宽、原持续判断与最新灰墨保护。水纹采用原分辨率裁片，按列检查。斧劈样图的收窄灰边和墨面亮点保留为待定。

| 留出参考 | 冻结模型 | 最新灰墨保护 |
| --- | ---: | ---: |
| 水纹纸缝区域的35个纸像素中被判为墨 | 0 | 0 |
| 水纹两侧墨线都进入输出的列数 | 8／14 | 8／14 |
| 斧劈收窄亮缝连续开缝长度 | 8／8行 | 8／8行 |
| 斧劈汇合区被预测为墨的像素 | 63／110 | 63／110 |
| 山体深墨面被预测为墨的像素 | 65／263 | 65／263 |

三张图没有出现旧持续判断提出的额外移除，因此保护区未退步，没有触发新版的墨边拦截。补筛同一画谱的另外三张图，在运行新版前核查了旧规则实际提出的4个像素。最新仍保留这4处开缝提议，其中2处有可见亮纸支持，另2处在房屋浅灰边和墨线汇合前的过渡，归属待核。

## 仍有失败

水纹的第590–594列和第600列漏掉了下侧淡水纹。纸缝区域没有粘连，当前限制来自冻结模型漏提一侧墨线。下一轮应先核查淡线保留与双侧墨线恢复，另收集旧延伸确实触及真实墨边的留出案例。未证明新版在独立图像上能拦下误切，暂未接入正式提取。

## 独立验证

完成三张原图的先标注后推理检查，以及三张画谱片段的触发条件筛查。图片来自项目现有资料，未用于这条灰墨保护规则调试，参考未经独立阅标。30项单元测试通过。500笔认可版和489笔工作版哈希核验通过，机械臂离线。

# 山河绘项目计划

> 这是上一版方案及实验索引。当前算法研发以 [MASTER_ROADMAP.md](MASTER_ROADMAP.md) 为准。旧方案里的硬件里程碑及 G3 启动条件保留为历史记录；新方案允许基于可靠样本开展树木与山石专项数字实验。

版本：2026-11-24（优先推进语义分割与拓扑融合）。依据用户再次确认的[四项固定目标](PROJECT_GOALS.md)与现有跨作品测试结果。

## 最终交付

系统依据用户需求组织山水构图，区分山石与树木，识别并复现对应皴法、枝干和叶法，输出完整笔触与墨带、有主次的对象及阶段顺序，最后由机械臂画出经验证的同风格山水画。

用户需求 → 有来源的国画知识 → 构图与对象 → 皴法／树法与笔组 → 完整笔触 → 顺序及可执行性检查 → 数字回放 → 实体毛笔与画面反馈。

## 二、四项目标及通过条件

| 目标 | 必须形成的能力 | 通过时需要的证据 |
| --- | --- | --- |
| G1 皴法辨识与复现 | 初期披麻、斧劈、混合／未知；定位笔迹，识别笔形与笔组依据，之后扩展类别 | 新作品上的类别、证据定位、困难反例和未知处理；后续固定石形改变皴法，笔组与墨带合理改变 |
| G2 山石与树木区分 | 识别对象与关键边界，再判断对象内部角色；避免叶、干、植被、点苔混入皴笔 | 独立作品的对象、边界和实例检查；明确报告树叶误入、淡山体漏分和交叠错误 |
| G3 树木画法 | G1、G2通过后，学习主干、分枝、枝叶与叶法，先松树再扩展 | 新树木的结构、完整笔触、叶法、笔组与依赖顺序；不能只给树种标签 |
| G4 整幅提取、同风格创作与实画 | 忠实临摹、按对象分阶段绘画、依据需求创作及真实墨迹复现 | 分别验证提取、数字重绘、生成、规划和实画，检查风格、构图、笔形、浓淡、遗漏、重复和可执行性 |

“懂皴法”采用上述可检验定义；类别名称、文字解释、漂亮的数字图或笔数下降不能单独证明能力。

## 三、阶段安排

### P0 基线与报告制度：本轮整理完成

建立基线哈希、统一目标、阶段状态和报告模板。旧权重、曲线、图片、排序及失败结果保留；任何候选单独保存。

交付：本计划、[逐轮报告模板](research/ROUND_REPORT_TEMPLATE.md)、机器可读实验模板，以及基线完整性核对。

### P1 可靠数据与知识／技能参考：当前优先工作

推进G1、G2，先围绕清晰完整山石及树石交叠，而非反复给少量参考点调参。

- 首批聚焦单一披麻、斧劈教程和可核实局部，保留混合及未知；逐步扩大皴法范围。
- 分开记录对象、外轮廓、内部结构转折、皴笔、点苔、染墨、设色及植被；非外轮廓不等于皴笔或不要画。
- 同时保存完整山石上下文、可见笔组、墨迹范围、曲线参考、来源与不确定性。视频可帮助核查过程，静态图无法确认的笔顺和物理参数保持未知。
- 训练、开发、测试按完整作品分组，核查重复及作者／发布来源；所有已查看作品明确标为开发或回归。
- 知识库保存出处、适用条件与案例；技能库保存可观察的对象、笔组、顺序和墨带。检索到说明不等于模型已经学会。

交付：可核查的整块山石参考包、树石困难反例、标签审计与冻结划分。专家／可靠复核测试与助手探索参考分别保存。

### P2 对象与皴法识别：两条主线并行验证

- 近期优先验证语义分割与原图墨迹拓扑融合。以语义分割提供对象证据，以端点、连续墨迹段及交汇关系提供结构证据。用相同墨迹支持比较仅分割、沿线融合及交汇融合，对歧义保留待核。
- 优先检查贴岩斜干漏提、树根接入岩面、树叶错分、山石轮廓与内部笔迹串线。分别计分原图墨迹覆盖、对象归属、连接正确性和待核比例，再评估树木学习、皴法解析和笔触重建可使用的数据。
- G1：完整山石＋局部笔组＋可定位形态证据；比较已有分类基线、上下文模型及笔组／概念监督，验证未知与困难负例。
- G2：对照国画专用分割候选，重点处理树石交界、树叶进入岩区和主山体遗漏；不追逐与绘画关系弱的总体分数。
- 输入、对象范围、可用提示和人工参与必须公开；给定裁剪或手工对象框的结果不称为自动发现对象。
- 轮廓、内部结构和皴笔分别评价。不能因抑制误报而接受大量主轮廓遗漏。

交付：新作品逐张预测、对应证据、类别／对象及未知指标、全部错例。门槛在开发集上确定并在新测试前冻结；样本不足或标签未可靠复核时不宣布正式通过。

### P3 完整山石与笔触：与P1、P2并行处理候选瓶颈

先用核查参考重绘一块山石，检查笔触表示与渲染是否足以复现；参考重绘与模型提取分开显示。再验证从静态画面恢复完整笔触及笔组，不能只输出局部名称或热图。

输出应包含对象、角色、完整曲线、墨带范围、相对宽度／明暗、笔组及未知；交叉或干笔断续处不强接。先与认可基线做同局部、同整幅比较，再在独立作品中验证。

把弱墨证据、正式掩膜、骨架和最终轨迹分开核查。先检验在已有弱墨支持的情况下，候选能否成段出现，再检验是否沿同一岩面、是否兼顾留白和近邻皴笔。保留无需猜测的断口及歧义，记录失败出现在哪一步。

交付：原图 → 核查参考 → 模型直接输出 → 数字重绘 → 分层回放。沿用21条主石局部接口；仅通过的候选进入逐步接入流程，不固定整幅必须500／700笔。

### P4 单Agent离线原型：工程验证可并行，不提前获得识别能力

先实现一个规划Agent，调用下述工具与确定性检查，不引入多个Agent互相投票作为标签或验收依据。

| 工具／模块 | 职责 | 输出边界 |
| --- | --- | --- |
| 国画知识检索 | 查找带出处的构图、皴法、树法规则和案例 | 规则与证据，不自动生成训练真值 |
| 对象识别 | 提供对象编号、区域、关系及不确定性 | 未通过的预测保持研究候选 |
| 皴法／笔触／技能模块 | 提供方法候选、笔组、完整笔触与状态 | Agent不能用文字猜测代替曲线和墨迹证据 |
| 计划检查与回放 | 检查依赖、遗漏、重复、对象切换和可用技能 | 不合格候选不进入实机动作 |

Agent管理目标、对象进度、已完成笔组、失败及下一步。输出结构化计划：对象ID、阶段、笔触ID、依赖、证据来源和待定原因；初期不直接生成任意机器人坐标或修改标定。

分开验收：

1. 给定可靠对象／笔触时，能否正确规划：这是规划能力测试。
2. 读取模型真实输出后，能否正确调用、保留未知和处理失败：这是端到端测试。

与同一组输入上的现有规则规划比较遗漏、重复、次序违反、无理由跨对象跳转及完成率；硬依赖仍由程序检查。若只复述既有人工计划、仅改善解释或不优于规则基线，则不采用。Agent不替代G1、G2的模型验证，也不解除G3阶段要求。

### P5 树木技能：G1、G2通过独立验证后启动

先松树主干、主枝、细枝、松针／叶组，再推广树种和叶法。此前允许整理资料及接口，不正式启动树木画法训练或宣称会自主画树。

交付：真实示范及可观察顺序 → 枝干与叶法识别 → 完整树木重绘与回放 → 独立作品验证。

### P6 整幅临摹与同风格创作

组件通过相应验证后，整合对象布局、主次、皴法、树法、完整笔触和依赖。先完成简洁山水，再扩大构图和画风。

临摹与创作分别评估；不能只让生成模型自己的分类头评价生成物。规划需要优于规则基线，实画需要通过单独墨迹检查。

### P7 实体毛笔与闭环

机械臂可用后，采集当前毛笔／墨／纸的线宽、起收笔、积墨、枯润、连续供墨、速度和下压响应。由短笔组、单块石头、完整树木逐步到整幅；以纸上实际效果验收。

项目当前默认离线。本计划不启动、连接、使能或移动机械臂；没有本机实测时不虚构数字宽度到下压的映射。

## 四、新模块逐步接入与回退

1. 冻结对应旧版文件、配置、来源与哈希；旧500笔及489笔工作基线保持可恢复。
2. 新模块单独保存，公开模型直接输出、人工参与、后处理及失败。
3. 先过格式、来源、轨迹完整性和阶段约束检查；这只算工程通过。
4. 在预先封存、未参与选择与调参的作品中验证对应能力；专家参考、来源标签与助手参考的证据等级分别报告。
5. 同条件整幅回归，检查主轮廓、皴笔、树木、笔序及重复覆盖是否出现实质退步。
6. 通过相应验证后，先局部、再对象、再整幅接入；保留版本、差异与回退入口。离线通过不自动授予实机就绪状态。

当前所有核心识别与实画能力仍未通过完整独立验收。研究候选、已知回归、独立通过、实画通过不得混用。

## 五、逐轮汇报与停止条件

每轮固定回答四项：**推进哪项目标、实际新增什么能力、还有哪些失败、是否通过独立验证。** 使用[报告模板](research/ROUND_REPORT_TEMPLATE.md)，附图和可复查产物。

没有新增能力就明确写没有；工程接通、人工参考、资料整理或回归恢复分别列出。报告比较冻结基线，不能只选较差旧模型或每组最好的一列拼成结论。

若连续同类试验只在熟悉局部上互相取舍，停止追加同类微调，先处理数据、标签、任务定义或完整输出表示。少笔数、更多训练轮数、更多Agent和更长解释都不是单独的成功标准。

## 六、下一轮具体任务

翟大坤和王概两幅已经用于淡轮廓、细枝和分块回放的诊断，现归档为 G4 的已知回归样本。弱墨候选和主干方向规则保留为可复用工具。当前研发轮次将主要投入 P1、P2 的跨作品识别。

[11 月 23 日复测](reports/20261123_recognition_groups.md)补齐了皴法笔组位置和树石双向错分图。下一批皴法样本需有同图的轮廓、枝叶、浅底和类外对照，重点验证拒识及依据位置。树石优先验证贴邻枝叶和岩面。11 月 16 日已经启用的两组归档作品不进入新作品盲测。

[皴法拒识和树石融合对照](reports/20261123_recognition_rejection_fusion.md)发现，两个拒识层仍放过米点，同时误拒了大多数目标参考；逐像素保护树区仍会误伤交界岩面。后续样本优先覆盖成组皴笔与点苔、米点的对照，以及同一树干到枝叶的连续归属。

[笔组形态与树石墨迹连通](reports/20261123_recognition_structure.md)用同一套归档复测确认，形态证据挡住了米点参考，也误放行了树木；源图连通减少了两批图的树误作石，但弱墨分枝尚未补齐。皴法需明确点苔与枝叶对照，树石需验证短断口及附近岩面保护。

[皴法对象核查与分枝短断口](reports/20261123_recognition_role_gap.md)挡住了三个已知树木错例，也挡下了一处披麻参考。分枝原图复核把枝间留白与真正漏分的末端墨芯分开，下一批应直接验证原图连续墨迹是否能补救分类候选的遗漏。

[树枝末端追踪与皴法归属](reports/20261123_recognition_attached_ink.md)恢复了已核查分枝的末端墨芯。冻结规则在另 14 张历史留出图中仍有增加岩面误归树的代价。皴法对象检查恢复一个披麻参考，同时重新放行两处树木。继续以交汇处的停止条件和枝叶归属为检验重点。

[枝梢停止规则与皴法归属复核](reports/20261123_recognition_branch_stop.md)对照了 26 张历史裁片。双侧墨脊要求保留了已核查枝梢并减少岩面变更，同时少找回一部分树区。后续优先核查浅枝、灰墨与岩纹相邻区段，皴法和对象归属冲突的位置保留待核。

[浅色树干与岩纹的原图复核](reports/20261123_recognition_weak_branch.md)定位了两段被挡下的浅色树干。短断口放宽和颜色一致性均未补回这两段。下一步按树干双侧轮廓与内部淡色核查完整对象，继续保护同图岩纹和留白。

[浅树干双侧轮廓与内部淡色](reports/20261123_recognition_full_trunk.md)已通过给定原图区域测试整段树干。邻干两侧对齐，两个浅树干仍出现错吸内部墨线或邻近底色。继续以成对外缘、内部墨线和树根混合区为重点。

[同一浅树干的外缘识别](reports/20261123_recognition_trunk_envelope.md)从连续色带、内部淡色与走向识别两侧外缘。已知对象的边界对齐有所增加，坡边误收与裁剪范围敏感性仍存在。继续验证在同图不同范围内能否稳定找回同一树干。

[树干外缘对裁剪范围的稳定性](reports/20261123_recognition_trunk_source_background.md)使用整张原图估计底色，改善了浅树干四种裁剪的一致性。坡边也被更稳定地误收；继续验证树干身份、岩面相邻边界与根部归属。

[坡边与树根混合区的树干归属](reports/20261123_recognition_trunk_identity.md)在已知区域退回了坡边候选，保留树根上方树身并暂停下方岩面。纵向裁剪仍会漏掉一段浅干，需验证叶丛遮挡附近的上接证据。

[浅树干多起点连接试验](reports/20261124_recognition_trunk_entrance.md)复测了纵向取景，找回浅树干中下段和树根上方树身。坡边对照保持待核，靠近叶丛的上段仍待独立作品验证。

[浅树干跨作品复测](reports/20261124_trunk_archive_transfer.md)在六组归档作品上复现部分漏检恢复，同时确认深色岩纹的树木错分来自对象归属层。保留这批错误作回归，后续优先核查独立的岩面归属证据与林下浅干外缘。

[邻近岩面与树干归属对照](reports/20261124_trunk_rock_context.md)在两批历史裁剪上测试了跨尺度岩面冲突判据。深色岩纹的四种范围均退回待核，仍需在不同作品的贴岩树干及岩纹误收上验证。

[冻结树石判据的归档复测](reports/20261124_trunk_rock_holdout.md)保留了前级生成的 12 个树干候选。贴岩斜干仍漏提，岩面粗标中的一处树根候选末端待核。分别核查斜干候选覆盖与树根末端归属后，再评估接入。

[首轮语义分割与墨迹拓扑融合](reports/20261124_scene_topology.md)已对照仅语义分割、沿墨迹段融合及交汇接续。交界处的两类误判略降，正确保留也下降。优先补浅斜树干的墨迹覆盖与树根交汇处的连接参照。

| G1 皴法识别 | 第一批做披麻、斧劈及混合／未知。分别登记有图注的教学例、可定位笔组、作品说明和困难负例。用局部皴笔形态及其在山面上的排列检验模型。 | 同一作品同时给出类别候选、墨迹证据位置和未知原因。按作者及作品留出，比较冻结分类器和新候选。 |
| G2 树石区分，与 G1 并行 | 用不同作者及画风的成组作品验证山体、树冠、细枝和交叠区。把细枝误入山石和淡山体漏提列为重点指标。 | 在同一套测试上报告树木、山石的识别、互相误判及边界错例，并把对象置信度传给皴法分支。 |
| G3 树木画法 | G1、G2 通过相应的独立验收后，训练松树主干、分枝和叶法，再扩展到其他树种。 | 新树木上的完整枝干、叶组、绘制顺序和数字重绘对照。 |
| G4 整幅提取、生成和实画 | 在通过的对象与笔法组件上整合主轮廓、整笔、对象笔序和同风格生成。现有两图仅作回归，用于检查整合是否引入退步。 | 分别交付整幅临摹、给定风格的生成，以及校准后的实体验证。 |

新候选先独立验证，再做整幅回归、局部接入与逐步推广。Agent 作为离线检索和规划支持单独验收。真实标签、自动输出和人工修订分别保留。

## 2. 三种场景分别要改什么

### A. 只换纸（纸挪了位置 / 换新纸）
1. `CanvasConfig.ROBOT_CORNERS` ← 四角实测
2. `ArmConfig.PAPER_Z` ← `main.py --calibrate-z`
3. 核对 `ReachConfig.Z_MAX ≥ PAPER_Z + PRESS_MAX_MM`
4. 颜料杯没动的话，只重新核对"离纸边 ≥20 mm"（脚本会自动查）

### B. 挪了颜料杯（纸没动）
1. `config.py` → `PALETTE[0]["dip"]`（黑盘中心）+ `["surface_z"]`（液面）
2. `pigment_measurements.json` → `black` / `red` 各四项
3. 黑盘的三处数值（`dip`、`PALETTE[0].surface_z`、`json black`）保持一致

### C. 换笔 / 改绘画姿态（换基准，改动最大）
1. `ArmConfig.RPY` ← 当前 RX/RY/RZ
2. `main.py --calibrate-z` → `PAPER_Z`
3. `main.py --teach` → 四角 + 水盂 / 擦笔布 / 试色区 / 色格
4. `main.py --calibrate-ink` → `PALETTE[0]["surface_z"]`
5. `pigment_measurements.json` → `rpy` + black/red 坐标全部重量
6. 已评审的山水/蓝色任务必须重新生成（脚本报 `Calibration changed` 是预期的）；
   梅花那条中断记录也会因快照不一致而拒绝 RESUME

## 4. 必须记住的坑

0. **速度别压到极低（<8% 有效）**：2026-09-26 用"8 个关键位姿读关节角"的诊断证明了
   墨盘段的问题**不是奇异点/限位**（J5 全程 ~90°，离手腕奇异最远；所有关节都在中段），
   而是**极低速爬行**——有效速度 6% 时墨盘段的横移/下扎/提起会间歇性触发保护性停止
   （黄灯 + `mode 11` + **报警码为空** = 力矩保护），而 ~15% 时同样位姿一次都不停。
   → 墨盘段（`dip_velocity_percent`）保持 **≥12%（有效 ≥8%）**，现在用 20（≈14%）。
   → 这条也解释了"关节一直抖"：低速爬行本身就是抖的来源之一。
   → 诊断脚本：`tools/_singularity.py`（走到 8 个关键位姿读 `GetAngle()`）。

1. **面板上的 `[X-]` / `[Y-]` 是按钮标签，不是数值的负号。**
   抄任何坐标前，先点动到位、跑 `uv run python scripts\check_pose.py`，以它打印的 `当前 XYZ`（User2/Tool0）为准。
   2026-09-25 就因为把按钮当负号，把画布镜像到了桌子另一边，`main.py --probe` 直接报警 17（逆解算错误）。
2. **`PALETTE[0]["surface_z"]` 和 `pigment_measurements.json → black.surface_z` 是同一个物理量**，改一处就要改另一处。
3. **`ArmConfig.RPY` 是基准**：动它等于换基准，所有坐标都要重量；反过来，量任何坐标时都必须保持这个姿态不变（**只点 X / Y / Z，绝不点 RX/RY/RZ**）。

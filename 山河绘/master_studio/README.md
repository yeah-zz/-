# 山河绘 · 名家笔触实验室

这是独立于原绘画工作台的网页创作平台，默认地址：

**http://127.0.0.1:8770**

双击项目根目录的 `启动名家笔触工坊.bat` 启动。原工作台（8765）继续负责机械臂执行；本平台负责“选名家 → 生成预览 → 选一幅 → 导出绘画包”。

## 现在能做什么

1. **五套内置名家笔法模型**：黄公望（披麻皴 / 浅绛）、倪瓒（折带皴 / 一河两岸）、石涛（湿笔 / 万点恶墨）、龚贤（积墨 / 米点）、八大山人（简笔 / 残山剩水）。
2. **四种气韵**：清远、苍茫、雄浑、萧散，改变留白、云气、墨重与干湿。
3. **六种山水构图**：山河重构、富春长卷、一河两岸、奇峰云瀑、黑密千岩、残山剩水。
4. **一次生成 2–6 幅预览**：四幅会改变山体数量/主峰位置/水口/树法/江面宽度，不是同一张图换种子。
5. **逐笔轨迹**：预览与轨迹共用同一组中心线、压力、速度；不是“先画图再猜路径”。
6. **抽象度控制**：参考 CLIPascene 的“忠实度/简洁度”分离，0.6 时纹理/苔点大幅删减，只保留骨线、主树、亭舟（实测 6k 笔降到 1k 笔）。
7. **细节密度**：直接控制碎笔保留率；0.7 约保留一半，1.3 保留全部并加密。
8. **轨迹后处理**：长平滑 B 样条、曲率降速、压力/线宽耦合；每点速度与压力都可导出，详见 [笔触轨迹与机械臂控制](docs/笔触轨迹与机械臂控制.md)。
9. **导出机械臂绘画包**：`painting.json`，格式与现有 `待画作品/.../任务资料/painting.json` 一致。可下载，也可一键保存到 `待画作品/新作品`；重启 8765 工作台后进入画库。导出/保存都不连接机械臂，仍需现场核对纸张、杯位、参数，不能直接运动。
10. **自定义风格训练**：上传 1–12 幅同一画家原作，统计墨色覆盖、边缘密度、笔向熵、留白、色度、冷暖，生成一套可解释的自定义笔法模型。

## 轨迹算法（v2）

- 中心线：较稀控制点拟合均匀三次 B 样条，再按弧长重采样。
- 曲率：一阶/二阶差分求每点曲率，7 点平滑。
- 速度：`speed = base × (1 − curvature_slow × k_norm)`，曲率越大越慢，限制在每家模型自己的 `min_speed` 以上。
- 压力：`press = press × (1 + press_gain × k_norm)`，补偿慢速造成的墨量变化，仍受 `PRESS_MAX_MM` 限制。
- 每家模型有独立 `motion` 参数：黄公望 0.42、倪瓒 0.48、石涛 0.32、龚贤 0.38、八大山人 0.50。

这不是神经网络训练，而是把“转弯慢、起收轻、长线匀”这些可解释的运笔习惯写进轨迹。导出包中的 `speed` 是逐点列表，不再是整笔一个常数。

## 笔法模型是什么

不是把某一张画做滤镜，而是把画史中可复核的用笔习惯拆成可执行参数：

- 线质：宽度、起收、提按、干湿、断连、抖动、复笔；
- 皴法：披麻、折带、斧劈、米点、雨点、乱柴，各自的笔向、长短、疏密与叠压；
- 点苔：沿山脊成组、大小、密度、聚散；
- 树法：松针成扇、阔叶介字点、枯枝疏点；
- 墨法：层数、浓淡、破墨、积墨；
- 构图：留白、主峰位置、平远/高远、边角；
- 题款：位置、大小、横竖、印章。

每套参数都能落到机械臂真正能画的点、压力与速度。预览图与导出的轨迹来自同一次渲染，不存在“预览很细、导出只有轮廓”的两套数据。

## 导出说明

- 导出使用 `find_export_python()` 自动寻找含 `cv2` 的 Python 3.10+；本机优先使用 `C:\Users\Lenovo\AppData\Local\Programs\Python\Python314\python.exe`，其次 `D:\Anaconda3\python.exe`。
- 导出的 `painting.json` 只包含黑线与蓝/绿上色；赭石只留在预览中。
- 苔点、飞白、断笔会被压缩为约 1500 条黑线，避免一次作画落上万颗点。
- 导出过程不连接机械臂，只做离线 `load_artwork + manifest_for` 校验。
- 现有工作台仍负责标定、速度、杯位、蘸取和逐笔确认；本平台不修改 `config.py`、`site_settings.json` 或五幅原画稿。

## 已知边界

- 这是“可解释笔法蒸馏 v1”，不是神经网络风格迁移；它追求的是**可画、可调、可解释**，不是生成照片级国画。
- 树、亭、舟、水口仍是程序化笔触，复杂真景的构图仍需人工挑选母题。
- 预览为风格草稿，实绘线宽、渗墨、颜色深浅受笔、纸、颜料、含水量和现场标定影响。
- 自定义训练是统计特征 + 规则映射；`_features` 与 `_spread` 已保留，后续可把特征向量替换为 CNN/CLIP 编码器。

## 公共图库与四类皴法 patch

`corpus/manifest.json` 收录 14 幅 Met Open Access 公共领域作品（黄公望一栏为后世拟黄公望，仅用于披麻皴统计）。当前已实际下载 96 幅（14 幅标注 + 82 幅预训练）、提取 1067 个山石 patch，四类 kNN 留一法准确率 **83.8%**（披麻 47、折带 20、斧劈 17、米点 15）；CNN 编码器验证准确率 75%（99 标注 + 205 预训练 patch）。图片在 `corpus/<画家>/`，patch 在 `corpus/<画家>/patches/`。

```powershell
python -m master_studio.fetch_corpus --artist all --limit 4
python -m master_studio.train_textures --extract --per-image 8 --patch 240
```

- 每幅图提取 240×240 山石 patch，按边缘/墨色丰富度筛选；
- 四类：披麻（黄公望）、折带（倪瓒）、斧劈（石涛）、米点（龚贤）；
- 训练“质心 + kNN”四类模型，输出留一法准确率到 `data/texture_model.json`；当前 83.8%，已回写到渲染参数；
- 8770 页面“图库”区可查看图片/patch 数、提取和训练；训练后 `corpus.apply_model()` 会把质心特征回写到线宽、皴密度、干湿和点苔。
- 当前图库已可用；Met 原图较慢，脚本优先取 `web-large` 版本。

本轮修改规划算法，没有训练新权重。输入采用上一轮保守曲线及已保存的原生细线候选，不采用已知有误删的学习式重复线判断。缓存的 SAM 掩膜与源图经过哈希及缩放后像素一致性检查。

每条曲线整体归属自动对象候选或明确标出的待定空间区。相同块内按轮廓／骨架候选、内部长线／皴线候选、细节／待定的顺序完成，再切换下块。内部长线还按方向及局部位置分组，保持组内顺序；方向组不是传统皴法类别。

后续接入执行端须完成单独的纸面坐标、笔宽和安全检查，并保持本轮完整计划身份。离线 plan.json 不能直接发送给机械臂。执行端可调用 `ExecutionJournal.append` 写入经过到位确认的事件，绑定文件需要 scene、精确 plan_sha256、唯一 run_id 及 journal 绝对路径。

## 验证及限制

`tests/test_hierarchical_paint_20261105.py` 检查白缝、近平行线、跨块、待定归属、新闭环、分层和方向组顺序，以及执行日志身份、完成依据和过期状态。浏览器检查验证三幅图播放暂停拖动、只读 HTTP 边界及离线／执行状态分离。

本轮仅改善顺序和少量连续性，不代表完整山石实例识别、传统皴法分类或毛笔复现已经完成。现阶段块数仍偏多、碎线仍多；先块内分层的约束可能增加空移，因此没有证明绘画时间缩短。实机防晕染还依赖实际笔宽、含墨量、起收笔和纸张标定。

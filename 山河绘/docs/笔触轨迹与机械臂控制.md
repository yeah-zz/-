# 笔触轨迹与机械臂控制

更新：2026-10-21。适用于 `master_studio` 名家笔触导出包与现有 8765 工作台。

## 1. 一笔到底由哪些变量决定

机械臂画的不是“线宽”，而是一段有时间、有压力、有速度的接触过程。当前导出包每个中心线点带三组数据：

| 变量 | 在导出文件中的字段 | 作用 | 现场建议 |
| --- | --- | --- | --- |
| 笔尖相对纸面的下压量 | `press`（mm） | 决定笔毛铺开程度、接触面积，是最直接的线宽变量 | 黑线 0.06–0.46 mm；先按现有 `PRESS_MAX_MM=0.80` 内使用 |
| 平面路径 | `points`（像素） | 决定笔迹形状 | 用平滑 B 样条重采样，不在转折处堆点 |
| 逐点速度 | `speed`（控制器 %） | 决定单位长度落墨量、转折是否过冲 | 曲率越大越慢；当前导出约 26–47% |
| 起笔/收笔速度 | `touchdown_velocity_percent`、`lift_velocity_percent` | 减少落笔冲击与收笔拖尾 | 起笔 20–30%，收笔 40–60% |
| 抬笔高度 | `lift_mm` / 执行器 `TRANSIT_LIFT_MM` | 避免蹭纸 | 现有 2.5 mm 左右，按笔毛长度调整 |
| 蘸墨量/回蘸 | `ink_execution.policy` | 决定一笔能画多长、何时飞白 | 现有容量 170 eq-mm，长线分段 |
| 毛笔姿态 | `RPY` | 决定侧锋/中锋 | 换笔或换纸后重新标定 |

**结论：主要靠控制笔尖到纸面的高度（下压量），但不是只控制高度。** 同样的下压量，速度快慢、毛笔含水量、纸的吸水性都会改变线宽和墨色。因此平台同时输出 `press` 与 `speed` 两条曲线。

## 2. 起笔、行笔、收笔怎么走

当前渲染器的压力包络和导出轨迹按下面的过程设计：

### 起笔

1. 机械臂在纸外/纸面上方高位移动到起点上方。
2. 以较低速度（`touchdown_velocity_percent` 20–30%）下降到“刚触纸”高度。
3. 下压量从 0.06–0.10 mm 在很短距离内升到目标值，形成“顿”的起笔。
4. 可停留 0.03–0.08 s，让笔毛吸墨、铺开；停留过久会积墨。

### 行笔

1. 中心线用平滑 B 样条重采样，避免把抖动当成笔形。
2. 曲率大的地方降速 20–40%，减少过冲和转折堆墨。
3. 压力按笔形中段略高、两端略低；长线中后段可略降，形成自然的“提”。
4. 墨量不足时按现有策略回蘸，不在一笔中间硬拖出干涩断线。

### 收笔

1. 最后 10–20% 行程逐渐减压，形成出锋或回锋。
2. 到终点后先抬笔（`lift`）再水平移动，避免拖尾。
3. 收笔速度可比行笔略快，但不要突然加速；急停会在纸面留下墨点。

这些动作在现有执行器里由 `module_lines()` 生成 `touch → draw → lift → raise` 序列，`z_for_press()` 把 `press` 换算成绝对 Z。平台导出的是同一套 `press`/`points`/`speed` 数据结构，没有另造一套运动协议。

## 3. 轨迹后处理（本版新增）

`master_studio/trajectory.py`：

- **长平滑 B 样条**：用较稀的控制点拟合一笔，再按弧长重采样；比逐点折线更接近“写出来”的曲线。
- **曲率估计**：对中心线求一阶、二阶差分，得到每点曲率；做 7 点平滑。
- **曲率降速**：`speed = base × (1 − 0.40 × k_norm)`，再乘压力修正，限制在 18–100%。
- **压力耦合**：曲率大时压力略增 7%，补偿慢速造成的墨量变化；最终压力仍在 `PRESS_MAX_MM` 内。
- **输出**：`points`、`press`、`speed` 逐点对齐；导出时写入 `painting.json`，执行器按点下发。

这不是“深度学习”，而是可解释的轨迹优化。它解决的是转弯过冲、速度恒定导致粗细一致、起收笔生硬这三个具体问题。

## 4. 标定：把 press 变成真实线宽

`press` 是相对纸面的下压位移，不是线宽。建议每次换笔/换纸做一次阶梯标定：

```powershell
python main.py --test-strokes
# 或
python scripts/press_ladder.py
```

记录每个 press 档位的实际线宽、墨色深度和飞白情况，回填到：

- `ShuimoConfig.PRESS_MIN_MM` / `PRESS_MAX_MM`
- `web/data/site_settings.json` 的纸面高度
- `master_studio/profiles.py` 对应名家的 `line.press_lo/press_hi`

如果纸面不平，优先使用带弹簧的笔夹或柔性笔架；仅靠 Z 位置无法保证恒定的接触力。

## 5. 从论文到本项目的取舍

- **CLIPascene**（Vinker et al.）：把“忠实度”和“简洁度”分开，用 MLP 学笔画放置与删减，CLIP 引导语义。本项目先实现“抽象度”滑杆和按角色保留/删减笔触；后续可把 `trajectory` 的笔触重要性评分换成 CLIP 特征。
- **Calligraph / Long Smoothing B-Splines**（Berio et al.）：用长平滑 B 样条和 jerk/曲率代价生成适合机器人复现的轨迹，曲率高处自然减速，宽度变化可映射笔压。本项目采用 B 样条 + 曲率降速 + 压力耦合，未引入 DiffVG 训练。
- **CoFRIDA**（Schaldenbrand et al.）：把机器人约束放进生成模型的自监督微调，并支持在人已画的画布上继续合作。本项目先把机器人约束写进导出与轨迹（速度上限、压力上限、安全边距），并保留“部分画布继续画”的接口；真正的在线协同需要后续接入相机与增量画布状态。

参考链接：

- https://clipascene.github.io/CLIPascene/
- https://colormotor.github.io/calligraph-page/
- https://pschaldenbrand.github.io/cofrida/

## 6. 上千幅原作的批量训练

平台上传接口一次支持 1–12 幅；更大规模用命令行：

```powershell
# 单个画家一个文件夹
python -m master_studio.train_corpus --folder D:\名画库\黄公望 --name 黄公望 --base huang_gongwang

# 根目录下每个子文件夹一位画家
python -m master_studio.train_corpus --folder D:\名画库 --per-folder --base ni_zan
```

当前 v1 统计：整幅特征 + 局部 192×192 patch 特征（暗墨比例、边缘密度、笔向一致性、粗糙度、线宽估计）。patch 学习专门吸收山石局部，不被整幅构图稀释。结果写入 `master_studio/data/custom_profiles.json`，刷新 8770 页面即可在名家谱看到。

**边界**：这不是在上千幅上训练神经网络。它把原作统计成可解释参数，能快速得到“像这位画家”的用笔倾向；要真正学习情感与判断，需要带人工评价的风格数据集、神经风格编码器和实机反馈闭环，这三项目前还没有数据。

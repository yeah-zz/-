# 昨晚G03_01实画粘连失败复核

用户提供的成画照片显示树冠、亭子和山石密集区域严重粘连，主要轮廓与细节被墨块覆盖。这是实画质量失败；1184条运动完成不能当作绘画效果通过。

本轮只读取保存的作业和照片，不连接机械臂，不修改冻结作业、共享配置、旧笔宽表或执行器。

## 保存作业能确认的事实

- 1184条曲线，1184次独立垂直落笔和抬笔；6572个笔压采样值均为0.60毫米。
- 每条曲线内部笔压恒定，没有在原曲线内加入渐入、渐收；`tail_mm=0`。这个字段本身不是缺陷：不能随意向原轮廓外追加尾巴；要研究在原曲线内部移动着起收笔。
- 保存作业里`width_mm=2.04`，来自旧笔宽表，不是当前毛笔/纸/墨的有效实测。
- 根据保存的四角映射计算，曲线长度中位数2.045毫米；327条短于1毫米，572条短于2毫米，573条短于旧估计笔宽2.04毫米。
- 方向无关、坐标取整0.0001毫米的完全相同线段重复18段，总长约8.208毫米，占总中心线4478.671毫米的约0.18%。这不能排除近平行重复、不同采样的同一路径或运行时异常，但不能把成片粘连全部解释为完全相同轨迹重复。
- 程序使用单笔连续队列和CP平滑，不应未经证据声称每个像素点都会停顿。控制器真实速度、受力和墨量没有测量。

## 已增加的检查与下一步

增加离线`drawability_gate`：没有当前毛笔、纸、墨状态对应的中段笔宽、起收笔直径和密集小样验证时，不允许用旧表回填为现时标定。即使数据齐全，也只进入完整计划复核，不自动宣称整幅可上机。**该检查尚未接到冻结执行器；不能说已禁止所有旧任务启动。**

六项测试验证保存坐标映射、反向重复识别、近平行与完全重复区别、旧表不能代替现时标定、单直线不能替代密集小样、有限笔宽使原本分离的中心线粘连。

之后优先处理：

1. 用当前纸笔墨测量真实中段线宽与起收笔墨团；固定其他条件后比较。先选合适的可分辨线宽，不继续仅增加下压或蘸墨。
2. 用这组尺寸检查每个模块的线间距、邻近墨带和端点密度；必要时采用更细笔、扩大画幅或明确生成细节简化方案，不能悄悄删除真实松针/皴线。
3. 继续恢复完整曲线，并试验在原曲线内部渐入、渐收的接触轨迹；不把“接成长线”和“模块排序”当作湿墨问题已解决。
4. 先验证亭子、树冠、山石各一个小局部的密集实画，再安排整幅。动作后果模型需要固定相机与逐笔前后图，当前最终手拍照只作为失败证据。

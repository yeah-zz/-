# 上色与勾线分模块

## 真机实验入口（新增）

在 VS Code 中直接运行 **`绘画/run_painting_experiment.py`**，或运行 `绘画/launcher.py` 选择 **18**。
Python 程序和现场配置现集中在 `绘画/`；当前参考图位于 `绘画/参考图/`，新实验结果存入 `绘画/输出/`。
根目录旧入口保留兼容转发，历史任务和 `robot_runs` 保持原位。
程序先按参考图实际执行稀疏上色，上色完成并回到纸外高位后才询问是否勾线。
选择不勾线即结束；选择勾线需等待颜色干燥并在纸外备墨。每种颜色连续执行，
只在换颜色时等待人工洗笔、补色，不逐笔询问。整个流程不自动蘸取未标定的颜料。

启动后输入参考图路径（回车用示例图），检查输出预览和当前标定；输入 READY 确认
新空白纸与已标定四角对齐、纸面高度/笔安装有效、路径已清空。每种颜色备好后输入 RUN。
这些确认会触发实际运动。新纸若厚度、垫板、安装位置或笔发生变化，须先重新标定。
机器人须已使能、空闲、无报警，并位于程序显示的纸外补色高位；异常位置不自动恢复。

执行器采用 20 mm 纸边余量，整条路径进入余量区就跳过并报告编号；不把路径挪到其他位置。
当前示例可执行蓝色 4 笔、黄色 2 笔、红色 2 笔；另外 2 笔黄色因边缘余量跳过，
勾线可执行 103 笔（其余边缘线跳过）。实际以程序输出为准。
运动前记录接触意图，异常或未完成接触会阻止下一次实验，防止不确定状态下继续。
日志在 `robot_runs/color_experiment_*.json`；故障后应检查现场和日志，不要直接删除记录重试。

实际上色指令使用下压 0.22 mm、行笔 v=15、全局 50%，移动 v=10；
沿一笔排队发送路径，不在每个路径点加入软件停顿，收笔到位后抬笔。
控制器仍使用 cp=0，转折处可能减速，不能保证完全匀速或不积水。
勾线保留自身下压曲线，实验行笔速度限制在 v=5–30，全局 50%。
目前均只通过模拟硬件测试，需实机验证宣纸和毛笔效果。

另有 `run_color_experiment.py` / 菜单 **17**，可在指定用户坐标空白区画 1–2 条短直线试色。

## 原离线入口

运行 `run.bat`，菜单 13 只上色、14 只勾线、15 先上色后勾线、16 先勾线后上色。
四个入口生成独立模块 JSON、各模块预览和总预览，输出到 `designs/`，不连接机械臂。
只选择一个模块时，不运行另一个模块的规划器。两模块使用同一参考图和坐标映射。

命令行示例（输出文件已存在时拒绝覆盖）：

```powershell
.\.venv\Scripts\python.exe main.py --mode painting --image samples/watercolor_landscape_reference.png --stages color,outline --job-out artifacts/watercolor/sparse_color_first_plan.json --preview-out artifacts/watercolor/sparse_color_first_preview.png
```

`--stages` 可选 `color`、`outline`、`color,outline`、`outline,color`。
`--strokes-per-region 1` 改为每块最多一笔；默认最多两笔。
`--sparse-brush-width 1` 指估计接触笔宽，单位 mm；不是自动标定值。

## 宣纸稀疏上色

将邻近色像素合并为连通色块，忽略小于 12 平方毫米的碎斑；每块最多 1–2 条顺势线，
过窄的块可以跳过。笔数上限在尝试不同笔宽时共享，不按明暗分层反复覆盖。
第二笔避开第一笔的沉积路径，留出空白让颜料自然扩散。预览只画生成的笔触，
不拿原图色面冒充实际效果，也不模拟宣纸水分扩散。红色也遵循稀疏策略，可能不能形成满圆太阳。

先上色时按空白纸规划；先勾线时，上色保留参考墨线间隙。
如果纸面已经有墨线，单独上色时应加 `--existing-ink`，但仍须确认图纸配准。
两阶段之间记录干燥检查及洗笔换色步骤，不用固定等待秒数假定已经干燥。

## 轻压、快走参数

上色独立候选配置：下压 0.22 mm（此前 0.30 mm），行笔 `v=15`（此前 `v=10`），
全局速度 50%，移笔速度仍为 10。落笔和中间路径点不添加主动停顿。
可用 `--color-press`、`--color-draw-speed` 调整候选值；不改勾线配置或旧任务恢复逻辑。
下压量并非力传感器测得的压力，须用当前毛笔和宣纸验证笔宽、含水量与笔触。

离线设计将这些值写入 `motion_candidate`；所有设计计划为
`ready_for_execution=false`，拒绝 `--execute` 或运动标定参数。计划没有机器坐标，
不能直接复用旧纸张的配准或直接发送给机械臂。上述真机实验入口另行转换、检查机器轨迹，
在确认新纸标定和现场条件后实际执行。旧实机入口保持原有行为。

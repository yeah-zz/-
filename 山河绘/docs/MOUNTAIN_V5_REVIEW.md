# v5：协调蘸墨与行笔，增加山体内部线

> **后续真机记录：** 用户明确确认新纸和标定状态后，v5已实际执行成功：94/94笔、791.8秒、16次蘸墨，墨内停留共10.2秒；实际轨迹2849点。四次休息后的补蘸均触发，最大周期结束墨龄60.875秒。结束mode=5、无报警、笔尖离纸60mm，保持使能并关闭TCP。实际补蘸数与离线预测20次不同，体现了实际时钟重新判断。以下正文保留离线阶段的参数和预测；实画浓淡改善尚待照片/用户验收。日志见 `artifacts/mountain/mountain_v5_job_execution_log.json`，实际轨迹见 `artifacts/mountain/mountain_v5_job_actual.json`。

用户反馈 v4 山形可以，但起初几笔太重、后段变淡，希望再多一些线条。实画照片归档为 `artifacts/mountain/painted_v4_user_photo.jpg`。本轮只做实现和离线验证，**没有连接或驱动机械臂**；原来的纸上已有 v4。

## 已确认的排程问题

v4 每次蘸墨固定 3 秒，只按 240 mm 总线长补墨；同样的长度下，重压宽线与轻压细线没有区别，三次 20 秒高位休息也没有更新墨量状态。末次蘸墨后连续安排了 25 笔，里面包含休息。

复核实际任务的 9 个蘸墨周期，实际路径长度分别约为 118/224/187/181/138/231/237/238/176 mm。采用现有估计笔宽换算成等效耗墨指标后，最大一周期为 274 等效 mm。该指标只是比较用的模型量，不是实测墨水体积。

照片中的起笔粗黑、后段干淡与上述问题一致，但照片不能排除纸面高度误差、笔毛拖曳、墨浓度等因素。**不能仅凭照片确定最佳蘸墨时长或储墨量。**

## 新版具体行为

`--ink-policy balanced` 启用独立的试验策略，原 `legacy` 和硬件标定保持不变。

| 项目 | v4 | v5 试验值 |
|---|---|---|
| 首次墨内停留 | 3.0 秒 | 1.2 秒 |
| 后续补蘸 | 3.0 秒 | 0.6 秒 |
| 蘸后高位沥墨 | 0.8 秒 | 1.6 秒 |
| 补墨依据 | 累计线长 240 mm | 长度×估计笔宽、实际墨龄、实际空闲时间共同判断 |
| 耗墨预算 | 不区分笔压 | 170 等效 mm，预留 25；每个切分段最多 120 |
| 时间窗口 | 无 | 含下一笔预计耗时，75 秒窗口；空闲达 15 秒重新补蘸 |
| 高位休息 | 每20笔20秒 | 保留；休息后实际时钟会触发补蘸 |
| 刚蘸墨后的起笔 | 原层级笔压 | 前12 mm从该层笔压80%渐回100%，不加压硬补淡墨 |

墨盘 XY、液面、插入深度 2 mm、纸面、姿态、坐标系、全局速度都未改变。没有增加擦碗沿、试墨区、洗笔等未标定动作。更短蘸墨并不意味着吸墨量与时间成线性比例；这套值是待实画验证的起点。

过长轮廓先在离线阶段拆为可供墨的笔段，优先选山谷位置；端点沿原轨迹提锋，共享同一个坐标，不添加跨白缝连线。若没有合适山谷，则在预算允许范围内取路径上的点。可能出现的接笔痕需要实画检查。同一层内优先选择附近且能用剩余预算画完的线，不额外画“消耗墨水”的假笔。

`run_mountain_balanced.py` 在每笔之前使用实际单调时钟重新判断，**不照搬离线预测的补蘸次数**。每笔记录实际耗时、墨龄、估计消耗、补蘸原因。若观察到行笔比预计慢，会收紧下一笔的耗时估算；如果下一笔即使新蘸也超出时间窗口，就在落笔前停止并要求重新分段，避免硬画。没有传感器检测纸上浓淡或笔上墨量，不能把这种时钟反馈称为实际墨量测量。

执行器保持高碗三步进出；所有蘸墨、沥墨和休息计时均在到达确认后开始；无自动清报警、自动重试或自动重新使能。最终实际下发轨迹另存，可用于事后复盘真实补蘸和压力补偿。

## 增加立体感

`--mountain-detail enriched` 增加源图里已有的下行结构，外轮廓几何保持相同。

- 构图线：70 → **90**；轮廓 23 不变，次级线 16 → 17，短皴线 31 → **50**。

- 其中4条长轮廓为供墨预算增加切分，因此实际执行为 **94 笔**（27/17/50），不是94条独立造型线。

## 离线结果及代价

本次预测 **20 次短蘸**，墨内停留合计 **12.6秒**（v4 为9次、27秒）；周期最大消耗约144等效 mm，预计最老墨龄约73.7秒。它是“少量多次”的保守方案，**蘸墨往返会变多**，不能宣传为速度更快。当前保守运动模型估计约20.4分钟，尚无v5实际耗时；v4实测为597.2秒。离线估时也受控制器混合与速度估值影响。

新增8项测试通过，加上原6项共14项。覆盖了慢速/延迟导致更早补蘸、停顿后刷新、蘸墨到达后才计时、压力加权耗墨、只降低新蘸后的起笔压力、长线切分保持几何、实测速率过慢时落笔前停止、校准快照变化拒绝执行、外轮廓保持及无网络CLI回归。自检通过。

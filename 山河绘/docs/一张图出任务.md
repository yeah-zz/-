# 一张图出任务 · 使用说明

整理日期:2026-10-01

## 一条命令

```powershell
Set-Location "E:\山河绘"
& 'D:\Anaconda3\python.exe' scripts\一张图出任务.py --image '参考图\你的图.png' --name '作品名' --check
```

产出一个目录 `输出\<作品名>_铺色版_<时间戳>\`,内含:

| 文件 | 用途 |
|---|---|
| `<作品名>_铺色版_黑线任务.json` | **可直接上机** `run_mountain_balanced.py --job <它>` |
| `<作品名>_铺色版_计划.json` | **可直接上机** `run_color_from_job.py --job <它>` |
| `<作品名>_铺色版_预览.png` | **黑线 + 上色合成预览**(黑线在预览里是画出来的) |
| `<图片名>_..._提取线稿.png` | 只看黑线 |
| `<图片名>_..._完整绘画.json` | bundle,`run_json_painting` 直接可用 |

## 内部五步(每一步都是独立进程,失败立即可见)

```
参考图
  │ ① unified_painting.py                     提线 + 建计划
  │      用 width_strokes(全分辨率 + 按墨线宽度分层)
  │ ② 建铺色源目录                            参考原图 + 黑线任务 + 计划
  │ ②b scripts\黑线简化到可上机.py             保留最长的一批,重建 waypoints
  │ ③ scripts\黑线下压补到落墨区间.py           整批加偏移,同步 waypoints 的绝对 Z
  │ ④ scripts\build_filled_landscape.py       稠密蛇形铺色 + 逐点色阶
  └ ⑤ 报告 + 两个离线校验
```

**顺序不能改**:必须先**简化**再**补偏移**。
反了会把密线压成黑块 —— 2026-10-01 飞瀑松崖 6474 笔直接补偏移,结果糊成一整块黑。

## 三个可调的旋钮

在 `scripts\一张图出任务.py` 顶部:

```python
TARGET_INK_STROKES = 1200   # 简化目标笔数。553 笔的黑线阶段约 30 分钟,所以按时间预算定
PITCH_MM = 0.774            # 铺色行距(层峦松水_双蓝长笔版验证值)
COLOUR_PRESS = '0.12,0.32'  # 铺色下压范围(生成器按原图局部浓淡分配)
```

命令行还有:

| 参数 | 说明 |
|---|---|
| `--name` | 作品名(默认用图片文件名) |
| `--check` | 最后跑两个离线校验 |
| `--keep-src` | 保留中间的铺色源目录(默认清理) |

## 实测记录(2026-10-01)

| 图 | 提取笔数 | 简化后 | 铺色 | 结果 |
|---|---|---|---|---|
| 梯田青峰 | 3804 | 1200 | 624 笔(覆盖 97.9%/91.8%) | 黑线清楚 + 蓝绿铺色 ✓ |
| 飞瀑松崖 | 6474 | 1200 | 1023 笔(覆盖 98.4%) | 简化前糊成黑块,简化后清楚 ✓ |

两个任务的 `--check` 均通过。

## 相关工具(可单独用)

```powershell
# 只提线(出笔触 json + 线稿预览, 不组装上机任务)
& 'D:\Anaconda3\python.exe' scripts\提取线稿.py --image <图> --preview <png> --save-strokes <json>

# 只简化(空跑不加 --apply)
& 'D:\Anaconda3\python.exe' scripts\黑线简化到可上机.py --job <黑线任务.json> --target-strokes 1200 --apply

# 只补下压(空跑不加 --apply)
& 'D:\Anaconda3\python.exe' scripts\黑线下压补到落墨区间.py --job <黑线任务.json> --apply

# 只铺色(自己建目录: 参考原图.png + 一个_黑线任务.json + 一个_计划.json)
& 'D:\Anaconda3\python.exe' scripts\build_filled_landscape.py --src <目录> --out-name <前缀> --pitch-mm 0.774 --shrink-mm 0.4 --colour-press-range 0.12,0.32 --travel-velocity 60 --max-stroke-mm 300 --reload-strokes 8
```

## 已知边界

1. **色区蒙版**:只认 blue / green / yellow 里有色区的部分;这张图的赭黄要靠 `build_ochre_layer.py` 单独补
2. **简化是"按长度砍"**:如果某张图的重要细节恰好都很短,会一起被砍掉。此时把 `TARGET_INK_STROKES` 调大
3. **笔宽模型未实测**:`ShuimoConfig.BRUSHES` 还是旧笔的数(模型 1.223mm vs 实测约 0.5~1.6mm,2.4 倍误差),所以行距/笔宽的对应关系是估的
4. **venv 已坏**:所有命令用 `& 'D:\Anaconda3\python.exe'`。`unified_painting.py` 依赖 numpy+cv2,Anaconda 已具备
5. **`--reload-strokes` 生成器 CLI 限 1~8**;流水线生成后会把计划里的 `reload_strokes_per_load` 提到 20(运行时限 1~40)

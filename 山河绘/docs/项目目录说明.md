# 项目目录说明

更新：2026-09-30。日常 JSON 入口为 `启动菜单.bat → launcher.py → run_json_painting.py`，续画状态由 `painting_session.py` 保存；图片制稿为菜单2的 `unified_painting.py`，不按题材分模式。提线与铺色模块仍保留历史文件名，名称不代表仅支持山水。

2026-10-09补充：运行代码、配套JSON及日志保持原位置；确认不参与当前网页绘画的旧材料已移到[本次归档](../archive/项目文件整理_20261009/整理说明.md)。当前目录以[文件夹导览](../文件夹导览.md)为准。

| 位置 | 内容 | 日常处理 |
|---|---|---|
| 根目录`.bat` | 菜单、小样、放弃旧任务 | 日常入口，按[使用说明](../使用说明.md)操作 |
| 根目录`*.py` | 绘画、运动、补墨、图像处理模块 | 相互按名称导入，不直接搬进新子目录 |
| `config.py` | 现场标定和运行配置 | 根据实测修改，修改后核对任务 |
| `pigment_measurements.json` | 墨盘、颜料杯数据 | 按当前杯位和液面维护 |
| `参考图` | 原始输入图片 | 保留，避免用路径预览再次提线 |
| `输出` | 不同版本预览、任务、运行记录 | 按同名前缀保存配套文件；续画文件单独辨认 |
| `archive/项目文件整理_20261009/旧画库` | 旧展示画库与旧已确认画稿 | 仅供追溯，当前画稿在“待画作品” |
| `robot_runs` | 共用上色日志和运行锁 | 不随意删除，不复制成第二套运行目录 |
| `scripts` | 离线生成、专项调整和维护脚本 | 多为特定画稿脚本；不少拒绝覆盖输出，不是通用菜单 |
| `tests` | 自动化验证 | 开发时使用，不是真机试画 |
| `tools` | 历史调试工具 | 先看代码用途，不能按名称随意运行 |
| `docs` | 当前辅助说明与历史评审 | 当前主入口为根目录使用说明 |
| `artifacts`、`samples` | 历史任务、参考资料和样例 | 可能仍被代码／测试引用，未删除 |
| `archive` | 历史流程、修改前备份、旧环境 | 用于追溯，不作为正常启动入口 |
| `.venv` | 当前电脑默认uv环境 | uv及日常bat使用，跨电脑可能失效 |
| `.展示运行环境` | 历史兼容环境 | 保留兼容旧命令，不是主环境 |
| `archive/项目文件整理_20261009/旧运行环境` | 已损坏的旧环境备份 | 不用于运行，已归档保留 |
| `.vscode` | 编辑器配置 | 使用工作区相对路径 |
| `pyproject.toml`、`uv.lock` | 依赖声明与锁定版本 | 换环境使用`uv sync --locked --python 3.12` |

历史说明保留原文件名和内容，并加上“以当前使用说明为准”的提示。历史文件里的旧目录、旧笔数、旧标定只代表当时记录。

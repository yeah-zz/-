# 纸面笔宽与起收笔绘画规划（离线）

用户暂停相机工作，要求继续处理整幅实画的粘连、碎段与起收笔。本轮只做离线规划和对照，不访问相机或机械臂，不改动原模型权重、共享标定、已执行任务。

## 改动

1. 复用三幅旧图的连续曲线候选。用纸面毫米单位简化同一曲线的冗余航点，偏差上限0.08毫米，端点保持，曲线数量不因此减少，也不跨线连接。这里只是186.8毫米画框的对照尺度，非当前机械臂标定。
2. 在曲线内部设计渐入、渐收的假设笔宽包络，端部相对宽度0.2，最大过渡长度0.8毫米；短线按自身弧长缩短过渡，不增加轮廓外尾巴。闭合曲线保持恒宽并标记接缝待定，防止凭空产生缺口。**笔宽包络不是下压量，未建立真实映射。**
3. 按0.6、1.0、2.04毫米三种纸面笔宽假设生成绘画候选。较长曲线及一定长度的闭合曲线暂作结构候选保留；密集、重叠的其他候选明确进入暂挂层。孤立短笔画不会仅因短而删除。
4. 在候选模块内优先安排结构，再安排细节；模块边界仍沿用未经专家验证的SAM候选，不当作真实山石实例真值。
5. 完整曲线全部保存到`complete_paths.json`，候选中明确列出每条保留/暂挂及其几何原因。暂挂不代表提取错误；保留长线不等于全部真实主轮廓完整。

## 对照设计

每张图、每种相同笔宽下依次比较：原图、全部曲线恒宽、全部曲线起收渐细、部分细节暂挂后的渐细候选。这样能分清起收变化与细节取舍，不用“之前2毫米、之后0.6毫米”的不同条件夸大改善。

所有灰黑视图均为几何墨带，不模拟墨色、墨量、干燥、晕化或毛笔变形；没有实画改善与用时结论。三张图都已见过，非盲测。本轮不训练提取模型或物理世界模型。

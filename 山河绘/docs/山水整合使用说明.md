## 两套代码差异与照片的对应关系

| 环节 | 原项目/目标项目证据 | 本次处理 |
|---|---|---|
| 山体结构 | 原 `LandscapeBrushGenerator._extract_continuous_ink_strokes` 保留源骨架、按长短分层。目标 `mountain.build_strokes` 从连通块上缘提轮廓，并筛掉短于约5.5–6mm的内部线；结构化版本还做山面筛选。 | 使用已有 `legacy_landscape_painting.py` 和适配器，默认保留≥1mm的短线，保持旧版笔顺和方向；不再用第二套上缘轮廓代替内部结构。 |
| 留白 | 第一张实物有断续皴线、明显留白。跨连通域接线可能抹掉这些间隙。 | 新入口默认 `directional_join_gap_mm=0`；继续检查源墨迹支持，不跨白区强行连成长轮廓。短线更少地被筛掉，但不会保留孤立噪点。 |
| 轻重 | 原引擎把源墨宽归一化为相对下压，并在密集区域减压；原配置允许约1.9756mm。目标常用山体层压力较浅，上限约0.24mm；当前毛笔总上限是0.50mm。 | 保留相对墨宽，增加可调的曲线响应、密处减压、笔腹起伏和起收笔；绝不搬用旧项目1.9756mm压深。当前整合上限仍为0.50/0.36/0.24mm，全部是待验证设计值。 |
| 实际粗细与预览 | `shuimo.press_to_width_mm` 低于现有表最小压力的部分被插值夹到约0.86mm；多种轻压因此显示近乎等宽。 | 单独展示压力意图，输出分位数；实机预检要求同笔同纸的压宽表覆盖所有下压点，并禁止宽度反推压力时外推。仍不能用未测表证明实物粗细。 |
| 坐标和驱动 | 原引擎旋转1024坐标并乘固定比例，旧驱动将XYZ格式化到0.1mm；目标用四角单应变换、当前纸面Z，驱动保留0.01mm。 | 复用 `CanvasMap`、`job.stroke_waypoints` 与现有E6接口，验证每个压力样本都传到Z；不复制原坐标、姿态和抬笔高度。 |
| 补墨与着色 | 原山水主入口生成轨迹后直接执行，没有逐笔补墨和换色排程；黑墨分支返回后不生成淡彩。目标已有供墨模型、稀疏淡彩和独立颜料站代码。 | 复用 `ink_control`、`sparse_color`、`PigmentStation`。低饱和灰绿/粉红不再被通用墨线掩膜错误提成黑轮廓；颜色按组执行，每笔淡彩保守补蘸一次。 |

两张照片没有与本次输入、当时笔具、标定和执行记录一一绑定。因此上表是代码中可确认的机制与照片现象的对应，不能证明某个参数是照片差异的唯一原因。

`sb.jpg` 的整合结果中，轮廓层压力p10/p50/p90约为0.081/0.240/0.404mm，短皴层约为0.009/0.076/0.149mm。压力层次已经传到XYZ；能否形成图1那样明显又自然的实物粗细，要用同一支笔的试线确认。

## 调整笔锋而不改山形

编辑 `landscape_integration_settings.json`，重新输出到新目录：

| 参数 | 含义 |
|---|---|
| `pressure_floor_mm` | 主体轻压基值；起收筆渐变仍可到0。默认0.04mm只是设计候选，不能视为已标定接触深度。 |
| `layer_cap_factors` | 长轮廓/结构线/短皴相对于当前 `PRESS_MAX_MM` 的上限比例。不会提高全局上限。 |
| `width_gamma` | 原图墨宽对压力的响应，默认0.75；调它会改变轻重分布，不改XY。 |
| `density_reduction` | 密集区域减压强度，避免内部线压成黑块。 |
| `belly_variation` / `belly_period_mm` | 沿弧长平缓起伏的幅度和周期；固定、可复现，不添加XY随机抖动。 |
| `entry_mm` / `exit_mm` | 在原路径内渐入、渐出；不额外画出锋尾巴。 |
| `min_length_mm` | 最短保留笔触；默认1mm，过短噪点仍丢弃。 |
| `directional_join_gap_mm` | 默认0，保留断续留白。改变它会影响几何，应重新逐峰检查。 |

`ink_policy` 可覆盖 `InkPolicy` 的预算、墨龄、初蘸/补蘸/沥墨时长等。等效毫米是耗墨估算，不是实测体积。长笔仅在预算内切段，片段共享端点，补墨发生在抬笔之后。运行时以真实时钟复核；如果实际行笔慢到一整段超出墨龄窗，会停止并要求重新分段，不在落笔途中横移去墨盘。

## 同一支笔的上色和换色流程

首次装墨前确认笔已洗净。墨线全部结束后，确认纸上墨迹干燥；移动到经验证的纸外高位停车点，人工洗净、擦笔控水，确认试色不带残黑，再装第一种淡彩。换下一颜色时重复洗笔、试色。默认色序是蓝、绿、黄、粉、红，可在设置中完整调整。

本次完成了**有人值守的同笔换色**，没有把现有水盂、擦笔布、试色区占位坐标接到自动洗笔动作中。`cleaning.mode` 仅接受 `manual`。自动洗笔的水盂/擦笔轨迹不在本次可运行范围，不能通过把模式字符串改成auto来启用。

上色为每色块1–2笔的淡彩点染，沿局部山势安排；不是满幅自动铺满，也不模拟宣纸扩散。目标颜色/透明度不能反推出可信的兑水比例，必须用实测配方。太阳等形状也可能仅表现为两笔色痕，应在预览中决定是否适合该构图。

## 需要现场填写的标定

复制输出中的 `calibration_template.json` 为个人标定文件，再填写；不要修改历史任务或模板里的计划哈希：

1. 确认当前 `snapshot` 中的User/Tool、姿态、纸面Z、四角、Z方向、速度倍率和高位转移高度。这些数值来自现有项目，程序没有宣布它们当前仍有效。验证后填写 `paper_verified`、`travel_verified`、`evidence`、`brush_id`、`paper_id`。
2. 同笔同纸同墨测量 `ink_width_table`，格式为 `[[下压mm,笔宽mm], ...]`。两列都必须严格递增，压力不能超出当前0.50mm限制，覆盖整条曲线（包括起收笔0压附近）。若0压不能稳定接触，先调整本次设计和现场基准，不填虚假数据放行。实测出平台段时，应保留有效的单调工作区并调整设计，不制造不存在的笔宽分辨率。
3. 对实际使用的每种颜色，填写 `color_width_tables` 和 `pigment_recipes`。表格必须覆盖该颜色的目标笔宽，否则拒绝外推并阻断上色。表可按不同颜料填写，但必须使用同一支夹持不变的笔。
4. `stations` 的键为 `ink`、`blue`、`green`、`yellow`、`pink`、`red`；只需填写实际用到的颜色。每项填写 `x,y,surface_z,rim_z,dip_mm,dwell_s,drip_s,strokes_per_load,verified,evidence`。位置和液面/杯沿高度必须来自同次坐标系与笔具测量。可对照现有 `pigment_measurements.json` 的字段和记录，但它只有旧次黑/红测量，不能直接推定其余颜色或继续有效。
5. `cleaning` 填纸外停车 `park_xyz` 和 `verified=true`，保留 `mode=manual`。软件要求停车点至少离纸20mm，并处于已验证转移高度或更高。颜料杯沿至少比高位横移轨迹低15mm；这些是检查阈值，不是对现场避障的证明。
6. 所有实测笔宽改变后，程序会重新核查**整段**淡彩轨迹到墨线笔迹的间距。变粗导致空间不足时，应减小着色宽度、增加间距或换设计，不能只关闭检查。

洗笔可能改变笔尖形状，纸张受潮也可能起拱。每次确认试色时同时确认夹持、触纸高度、纸张固定未变；发生变化要重新标定并生成计划。没有记录之前，保留 `hardware_enabled=false`。

## 续画

离线审核支持“已确认完成的笔触ID连续前缀”。填入 `resume_template.json` 的 `completed_stroke_ids`，核对真实完成记录后设置 `contact_reviewed=true`、`uncertain_contact=false`：

```powershell
.\.venv\Scripts\python.exe scripts\review_landscape_plan.py --plan 输出\山水整合_第一次\plan.json --resume-record 我的已核对续画记录.json --out 输出\续画审核.json
```

续画重新安排清洁/装墨或干燥/洗笔/试色/装色，不假定长时间停顿后原来的笔仍可用；不重画已完成前缀。

实机续画只接受本执行器在同一个 `robot_runs` 下生成的日志，通过 `--resume-record` 指定最近一条。只要有 `pending_event`、半笔接触不确定、计划/标定变化或分叉尝试，就拒绝自动续画。仅人工移动回高位并不等于纸上接触已核实，不能删除pending字段来绕过。旧版彩色实验未解决的中断同样会阻止新运行。

# 模块与连续笔画离线实验（2026-11-04）

用户希望完成一个山石等对象后再转下一对象，并减少碎线、重复起落和墨团。本轮不连接或移动机械臂，不改写已经执行的任务、冻结模型或共享标定。

## 论文如何使用

GWM（ICCV 2025）利用动作条件的3D Gaussian未来状态预测，支持策略学习；原论文没有验证毛笔、纸张和墨水。这里借鉴“当前画面状态＋候选动作→后果评估→下一动作”的结构，先实现二维离线规划。**没有复现3D GWM，没有训练真实墨水动力学，也没有实现相机视觉闭环。**

原始资料：https://gaussian-world-model.github.io/ ，https://arxiv.org/html/2508.17600v1 。

## 实际实现

1. 新增E盘独立SAM ViT-B推理环境，复用现有CUDA Torch。Meta官方375,042,383字节权重，SHA256 `ec2df62732614e57411cdcf32a23ffdf28910380d03139ee0f4fcbe91eb8c912`。预训练推理，未微调。24×24网格与原中心线最长128条的中点提供自动提示，不读取手工对象多边形或样本专用坐标。
2. 生成对象候选，合并嵌套的部件/整体候选；整条曲线归属，不在模块边界切断。SAM掩膜没有经实例真值验证，不会自动保证一块石头就是一个模块。未明确归属的线单独按局部位置组织，明确标为待定，不能当作已识别对象。
3. 恢复连续曲线：近端点、墨迹依据、走向与竞争判断；唯一的度二转角可以保留较大弯折；分叉处竞争不清则待定。不同模块不接，白缝不接，近平行线不横接，不新造闭环，不再用19.8毫米上限截断离线候选。长曲线不是已验证可一次完成的实机笔画。
4. 模块锁定：当前模块内的全部已归属曲线完成后，才切换下一模块。内部同时考虑新增覆盖、空移和近期命令墨迹的几何重叠。掩膜/墨带都仅为图像坐标，不含机械臂命令。
5. 每条新曲线保留原曲线索引、方向，每次连接保留间距、转角、支持度与待定竞争。全部原曲线保留，没有通过删细节降低数量。

G03_01与此前“长度÷(1＋距离/10)”算法在同一批输入上重新规划：模块切换418→58、模块回访360→0。但506条原曲线的对象归属仍不明确，数学上的模块不回访不等于真实对象已完整识别。空移距离16542→20124像素，反而增加约21.7%；局部完成与最短空移存在取舍。近期起笔接触代理374→221，但平均近期墨带重叠0.194→0.228，另一项退步，不能据此认定防晕墨已解决。

还提供全局长线优先对照，以及“只重排、不接续”的消融；不能只挑最差对照宣称大幅加速。所有统计见E盘`results.json`，旧图线条并不构成完整艺术家分笔真值。

## 尚未达到的要求

仍有大量真实或错误的短候选；SAM也不能稳定识别完整松树和所有山石边界；没有同笔真值准确率和实测纸面改善。因此本轮是新的分层规划候选，**不可直接上机替换**。

下一阶段优先补完整对象及整笔关系，修正归属不清与连接竞争；用同图局部检查完整笔画是否真被恢复。实际渗墨预测需要固定相机、纸面配准、逐笔前后图及动作/含墨历史。现有最终手拍照有遮挡且未配准，只能辅助诊断，不能当作逐笔动力学训练样本。接入这些数据后，才训练动作条件的二维墨迹后果模型，并验证连续起收笔与局部湿墨控制。

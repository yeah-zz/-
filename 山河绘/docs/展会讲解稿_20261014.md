**山河绘展会讲解稿**

适用：领导巡展，3—5分钟详细介绍。整理日期：2026年10月14日。

**项目定位与讲解重点**

建议对外定位：“山河绘是一套将参考画稿转化为真实毛笔动作的机械臂绘画系统，面向传统山水画的展示、互动与教学。”

讲解按“看见的成果 → 如何实现 → 技术难点 → 应用价值 → 下一步”推进。重点记住三个词：真实毛笔、完整流程、人机协同。

当前有勾勒、题字和上色的实机执行记录；系统仍在持续完善纸上效果和长时间运行稳定性。文化展陈、教学和科研是适合继续拓展的方向，现有材料没有证明已商业化部署。

**3—5分钟可直接讲的版本**

以下正文约1000字，结合指向作品、毛笔和大屏的动作，适合3—5分钟。以《松瀑亭舟》为例；如现场选择其他作品，替换第二段的作品名和画面元素即可。

各位领导好，我们展示的项目叫“山河绘”，是一套把图像处理、笔触规划和机械臂控制结合起来的毛笔绘画系统。它以中国山水画为主要展示内容，将参考图转化成机械臂可以执行的笔触，用真实毛笔、墨和颜料在纸上完成勾勒、上色，以及预设的“山河绘”题字。

这里以“松瀑亭舟”为例。请看这幅画，里面有山石、松树、亭子、瀑布和小舟。系统需要把画面中的墨线和蓝绿色区域整理成有顺序的笔触，再转换到现场纸张的坐标中，安排每一笔在哪里落下、沿什么路径行进、什么时候抬笔和补蘸。

整个操作可以分成三个环节。首先选择现有作品，或者上传新的参考图制作画稿；然后在网页中检查和编辑笔触，包括删除零碎线条、调整笔序、设置铺色间距和下压量，并通过逐笔预演查看绘制过程；完成画稿检查和现场准备后，再交给机械臂执行。操作者负责画稿审阅、洗笔换色和现场准备，机械臂负责绘画轨迹和补蘸动作，双方各有明确的分工。

这个项目的技术工作，主要集中在三个方面。

第一是柔性毛笔的运动控制。毛笔接触纸面后会发生变形，笔尖的下压量会影响接触范围和线条表现。我们在轨迹中加入下压设置，结合落笔、行笔、抬笔和收笔动作，让不同笔触可以采用不同的参数。这些参数需要结合实际使用的毛笔和纸张进行校准。

第二是绘画过程中的供墨管理。连续画线会消耗笔上的墨液，停留时间也会影响后续笔触。系统根据行笔量、估计消耗和时间规则安排补蘸，把蘸墨、蘸色和回到纸面继续作画连成一个执行流程。换色时，系统会停靠等待，操作者洗净毛笔、准备好下一种颜色后再继续。

第三是把制稿、控制和展示整合到同一个工作台。我们既能在实绘前预演，也能在实绘时查看已完成笔触。机械臂每确认完成一笔，网页就同步添加一笔，并更新阶段进度；这个过程还可以投到大屏，让观众看清一幅山水画怎样逐步形成。根据展示需要，也可以单独选择勾勒、上色或题字阶段。

我们希望它进一步服务于三类场景：在文化展陈中，让观众近距离观察毛笔作画的过程；在教学中，把图像处理、坐标映射和机器人控制放在同一个可操作的案例里；在研究中，利用现有平台继续测量和改进不同纸笔条件下的笔触表现。

目前项目已经有实机绘画运行记录，我们正在继续优化画稿、现场参数和运行稳定性。下一步计划加入对纸上笔迹的视觉测量，再研究如何根据实际线宽、浓淡和断线情况调整后续笔触。

通过“山河绘”，我们希望把传统山水画的表现形式，转化成观众看得见、可以参与、也便于教学和研究的机器人绘画过程。

**现场演示如何配合讲解**

1. 开场先指向真实纸上作品和机械臂，说明“真实毛笔、墨、颜料与纸张”。实物作品由现场准备；网页参考原图和路径预览应按各自性质介绍。
2. 讲制作流程时，切换参考原图与画稿预览。可以播放预先准备好的逐笔预演，并明确“这是同一份画稿的离线预演”。
3. 讲技术时，展示已经在现场验证过的勾勒或题字段落，让机械臂作画与讲解同步进行。领导停留期间不必等待整幅作品完成；展示需沿用对应纸面标定和现场操作流程。
4. 讲展示平台时，指向大屏：每笔由执行器确认完成后再添加，屏幕呈现已完成的计划笔触。
5. 收尾时回到实物作品，讲文化展示、教学体验和后续研究的方向。

已有记录中，《松瀑亭舟》对应的一次勾勒为145笔、约16.2分钟，一次题字为13笔、约3.7分钟。它们只是特定版本和参数下的阶段记录；展会不宜让领导等待完整彩画，也不应将这些记录相加作为整幅作品的保证时间。可提前开始已验证的阶段，领导到场时看正在发生的真实作画动作。

**领导可能追问的回答**

- “这幅画是机器人自己创作的吗？”
  
  “目前由参考图出发，系统提取和规划笔触，操作者可以审阅、删改和调序，再由机械臂执行。我们现在重点解决的是把画稿转成真实毛笔动作，以及把绘画过程组织好。”

- “里面用了什么人工智能？”
  
  “当前主要采用图像处理、轨迹规划和绘画流程控制。下一步计划接入纸上笔迹的视觉测量，再研究根据实际线宽、浓淡和断线情况调整后续笔触。”

- “技术难点和你们的工作体现在哪里？”
  
  “主要在柔性毛笔的下压和行笔控制、耗墨过程中的补蘸安排，以及图像制稿到机械臂执行的整合。毛笔、纸张和含水量都会影响最终笔迹，所以还需要持续做实物试画和参数校准。”

- “和打印画有什么不同？”
  
  “这里由机械臂握着真实毛笔接触纸面，执行落笔、行笔、抬笔和蘸取动作。观众能看到画作逐笔形成，也能观察毛笔、墨和纸相互作用带来的效果。”

- “是否能全自动完成？”
  
  “画稿确定、现场准备好以后，机械臂可以执行对应阶段的笔触和补蘸。画稿审阅、洗笔换色、判断墨干以及现场标定目前由操作者完成。”

- “可以换成别的图吗？”
  
  “可以上传新参考图，提取勾勒、规划蓝绿色区，经过预览、人工整理和执行检查后加入画库。浅底、轮廓清楚的图比较适合现有流程，复杂照片需要更多检查与调整。”

- “文字能随意写吗？”
  
  “当前示范作品使用预设的‘山河绘’字形轨迹。任意文字生成和书法笔法需要另外开发、验证。”

- “一幅画需要多久？”
  
  “用时取决于画稿笔数、轨迹、补蘸次数和人工换色。我们以本次展出版本的现场实测用时为准，离线预演的播放倍速不能代表机械臂实际速度。”

- “下一步想怎样落地？”
  
  “可以先探索文化展陈和教学体验这类看重过程展示的场景，积累现场运行经验，再完善内容库、操作流程和不同纸笔条件下的效果稳定性。”

**事实口径**

- 下压量是笔尖相对纸面基准的位移设置，单位毫米。实测接触力、力反馈控制尚无当前主流程证据。
- 补墨按行笔量、估计消耗和时间规则安排；液面补偿也是按规则调整蘸取位置。
- 实机实时画布由完成事件驱动，展示执行路径；当前主流程没有纸面相机回传或根据实际笔迹纠偏的链路。
- 题字是预设字形轮廓描绘；上色主要使用当前现场支持的蓝、绿颜料。
- 网页支持本次运行内的暂停和继续，当前笔完成后停靠；终端另有保存续画机制。网页重启后的自动续画不属于现有功能。
- 当前画库注册六份内置材料，第六份有隐藏标记，前五幅为主要可见山水作品。对外说“已有山水作品库”即可。
- 成功日志支持对应阶段执行完成；纸上线宽、浓淡、渗色、总运行精度、成功率和商业化成效需另外实测。
- 世界首创、全自动洗笔、任意图片一键复现、任意书法文字、自主艺术创作等表述超出现有证据。

# 原图约束提线 v2（2026-10-22）

针对山水样本中 CLIPascene 出现的偏移、绕圈，以及旧提线器漏掉深蓝山脊的问题，新增 `source_ink.py`。v2 从图像中提取可见墨线中心，不重新生成构图。

## 实现与接入

- 对纸色做保守归一化，双边滤波降低细小明暗扰动。
- 同时利用亮度和最大颜色通道，进行多尺度局部暗线检测。饱和度高不再成为直接排除墨线的条件；平整色块不会仅因颜色深就被整体填入墨线掩膜。
- 强弱证据有界扩展，避免一个强种子蔓延到整片水彩纹理。保留紧凑深色点候选，单独输出，不自动变成点按任务。
- 细化为中心骨架，按图结构追踪，避免拐角像素的对角捷径。只修剪附着于分叉的极短末梢。
- 连接共享节点时检查切线；连接断口还要检查距离、两端朝向和原图弱墨线支持率。留白不能只因两端接近就被跨越。
- 用有误差上限的折线简化取代自由移动控制点。默认误差为 `max(0.6, 0.55 × 图像长边/1110)` 像素。机械臂笔触适配时保留每个拟合顶点，再在段内加点，避免等距重采样削掉屋檐等折角。

`unified_painting.build_plan()` 新生成计划默认使用 `outline_engine='source-constrained-v2'`；可显式传入 `'legacy'` 使用此前的全分辨率提线器。已保存的五幅画稿与机械臂任务没有重写。

适配器保留原先 0.06～0.30 mm 的保守宽度到下压映射，并遵守现场配置上下限。这是未标定的候选位移，不能当作测得的笔宽或压力。没有修改现场参数，也没有运行机械臂。

## 复现离线预览

在项目目录运行：

```powershell
.\scripts\preview_source_ink.ps1
```

处理自己的图片：

```powershell
.\scripts\preview_source_ink.ps1 --input 'E:\图片\山水.png' --output 'F:\山河绘\山河绘\offline_previews\自己的样本'
```

启动脚本设置 E 盘缓存和临时目录，用已有 `E:\Anaconda\python.exe` 运行，不安装依赖。输出图像、原坐标 SVG 和 JSON；JSON 没有机器人坐标，`ready_for_execution=false`。

本轮结果在 `offline_previews/source_ink_v2_20261022/`：

- `method_comparison.png`：原图 / 此前 CLIPascene 第 2 层 / v2。两种提线结果均重新按原图坐标栅格化为 1 px 线宽。
- `comparison_overview.png`：原图 / 旧提线器 / v2 / 红线叠加原图。
- `detail_comparison.png`：山脊、松树分叉、亭子三个固定窗口的同坐标对照。
- `paths.json`：480 条几何路径、每顶点光学线宽和参数；是原图像素坐标。
- `ink_mask.png`、`weak_evidence.png`：中间识别结果，便于定位漏线和误检。

用与此前 CLIPascene 实验完全相同的 1110×750 裁切输入，未对结果手工删线或补线。旧提线器与 v2 均用完整输入分辨率；此前 CLIPascene 在 224×224 模型空间优化、再映射回原图，所以这不是计算条件相等的模型排名实验。

## 验证与已知限制

`tests/test_source_ink.py` 检查饱和彩色线、平涂色块、留白断口、分叉、折角、闭环、纸色噪声、边界及确定性。`tests/test_source_ink_integration.py` 检查适配器逐顶点保留、采样间距、配置限幅，以及完整新计划的共享坐标和禁用机械臂实例化。

最终 11 项定向测试全部通过，日志保存在结果目录 `test_report.txt`。另用 `scripts/check_source_ink_plan.py` 对实际山水输入运行完整计划检查：480 条基础笔触、耗墨分段后 482 条，坐标和逐点线宽对齐检查通过。执行任务未保存，`ready_for_execution=false`。计划检查摘要为 `planner_summary.json`，计划线稿为 `planner_centerlines.png`。

低分辨率输入的检测核设有像素尺寸下限，避免随着图像缩小，检测核反而小于实际栅格线宽，导致连续粗线被切成碎段。

检查的是可见线条几何与接口兼容。没有人工完整墨线真值，因此不报告这幅画的“提线准确率”。单图视觉上改善显著，不代表已验证所有国画风格。

目前仍会把部分深色水面倒影和水彩纹理识别为墨线；松枝细线仍有碎段，远山浅墨可能漏掉。短路径筛选也可能损失真实皴点。后续优先按山石、树木、建筑、水面区分线条保留策略，再做笔触角色与运笔标定。

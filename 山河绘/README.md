# 山河绘

日常只需提供一份本项目的绘画 JSON。网页可自由选择勾勒、上色和题字；每阶段完成后停靠，再选择下一阶段或结束。原终端入口保留先黑线、再选颜色的流程。

2026-10-20 已按“保留原来五幅图实绘”清理历史材料。当前工作台和菜单优先使用 `D:\Anaconda3\python.exe`；五幅画稿、现场参数及运行状态保持不变。保留范围与清理结果见 [文件保留与清理说明](文件保留与清理说明.md)。

## 山河绘前端工作台

双击 `启动绘画工作台.bat`，在网页选择“待画作品”里的五幅图之一。
五幅画的原图、完整画稿、分拆任务、顺序索引和预览统一放在“待画作品”的五个编号子文件夹。网页直接读取对应“任务资料/painting.json”，无需旧“输出”“已确认”“展示选画”目录。程序与配置保留在项目根目录，当前使用项目外的 `D:\Anaconda3` 运行环境。详见 [材料库说明](待画作品/使用说明.md)。
在“本次先画”选择勾勒、某种颜色上色或题字，点击开始绘画并确认现场准备后，后台连接机械臂；空白画布随已完成笔触更新，同时显示各阶段与全画稿进度。
每阶段完成后停靠，可选择任一未完成阶段或直接结束：可以只上色、只题字，也可以勾勒后直接题字。离线预演支持相同选择。网页默认不保存续画进度，实时画布使用本次内存状态；“暂停作画”“继续作画”用于当前阶段，结束后重开从新选阶段第一笔开始。在同一纸面补画其他阶段需保持纸张位置和标定一致。“清空之前作画记录”在任务退出、现场确认后重置画布并归档旧记录。
详见 [前端使用说明](web/README.md)。原终端入口保持可用。

网页右上角“修改参数”可调整纸面高度、黑墨/蓝色/绿色液面及杯位、蘸取参数和液面下降补偿；参数界面不提供速度、倍率或加速度调节。保存通过画稿检查后，下次网页绘画自动使用；原画稿 JSON 和原终端配置保留。机械臂任务未退出时只允许查看。2026-10-10按用户最新要求，网页新作业的纸面行笔速度指令在此前提速后再翻倍（前五幅48→96，简化单线稿24→48；相对原画稿为2.4倍，上限100）；空移、蘸取及加速度保持原设置，详见 web/README.md。


## 名家笔触实验室（新）

双击 `启动名家笔触工坊.bat`，打开 [http://127.0.0.1:8770](http://127.0.0.1:8770)。这是独立于 8765 工作台的创作平台：先选黄公望、倪瓒、石涛、龚贤或八大山人的笔法模型，再选山水母题，一次生成 2–6 幅预览；选定后可导出为现有工作台可读的 `painting.json`。导出只生成画稿，不连接机械臂；仍需在 8765 工作台核对纸张、杯位与现场参数后开始。

平台把线质、皴法、点苔、树法、墨法、构图、题款拆成可执行参数，预览与轨迹来自同一次渲染。新增“抽象度”控制、B 样条平滑、曲率降速与压力耦合；导出包中的速度是逐点变化，不再整笔一个常数。也支持上传同一画家的原作，或用 `train_corpus.py` 批量训练自定义笔法模型。详见 [名家笔触实验室说明](master_studio/README.md) 与 [笔触轨迹与机械臂控制](docs/笔触轨迹与机械臂控制.md)。

## 日常入口

双击 `启动菜单.bat`：

1. **读取 JSON 绘画 / 继续上次绘画**：拖入 `_完整绘画.json`，核对纸张和笔，输入 `RUN`。
2. **从图片生成绘画 JSON 和预览**：没有画稿时使用。新输出包含单文件完整绘画包。
3. **放弃旧任务（换新纸）**：先停止旧程序；作废未完成黑线、上色和整幅画续画记录，保留画稿与日志。

运行中只显示当前阶段的单行进度条，详细运动记录写入日志。换色、暂停和故障时仍显示必要提示。

## 暂停与继续

绘画时按 **P**，程序完成当前笔、抬笔并停到纸外。输入 **C** 继续当前计划；输入 **Q** 保存退出。没有超时或自动继续。

调整未画部分：P → Q → 修改同一份 JSON → 重新选入口1打开。按已完成笔数从下一笔续画，黑线和每种颜色分别记进度。纸张、画布坐标与笔尖标定保持一致，已画笔触不得修改或重排。C 不会热加载对 JSON 的编辑。

急停、断电、Ctrl+C、半笔中断不能按正常暂停直接续画，需核查运动记录和纸面。P 不是即时急停。
